# C0090 — A release archive's sha256 is not its binary's; prove a binary by the extracted file
tags: pin,hash,toolchain,provenance · date: 2026-10-02 · phase/task: 1.7/T1 · origin: mmx6 T1

A pin like `sha256 932ed366…` on `gcc-2.95.2-psx.tar.gz` covers the archive, not the `cc1` inside. A "same binary" proof extracts the file and hashes it; name what every recorded hash covers (archive, member, tree digest).
