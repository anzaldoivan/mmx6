# Constant dividend loaded before an abs branch: write the abs as a ternary inside the divide expression

Symptom: the code divides a constant by an absolute value. The target materialises the constant dividend before the abs branch, and our build materialises it after the branch (sched residual).

Cause: an abs written as separate if-statements on a local lets the constant propagate to the divide site.

Lever: write `q = K / ABS(x);` with ABS as a ternary macro inside the expression. This keeps the constant in the block before the branch. Pinned dividend locals did not help.

Evidence: W13 rock_08 F2814 (c33 87/87, 5 probes).
Related: C0152 (divisor in a local), C0144.
