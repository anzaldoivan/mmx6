# A container pull overwrites host-only edits to config/ files
- `mx.sh pull <path>` copies the container's file over the host file. A pull never merges.
- An edit made on the host after the last `mx.sh sync` is lost when that path is pulled. This includes a developer's
  `raise` line in `config/debt-baseline.txt`.
- 2.6/T9: the developer's raise line was reset twice (21:17, 21:37). The likely cause was a pull of a container copy
  that lacked the line.
- Lever: `mx.sh sync` after any host edit to `config/`, before any pull. Better still, commit the host edit first.
  Never pull a config file that the host changed since the sync.
