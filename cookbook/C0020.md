# C0020 — PCSX-Redux -portable keeps config in the run dir. With spu.Speed = 0, the emulator runs unthrottled
tags: pcsx-redux,portable,speed,headless · date: 2026-10-01 · phase/task: 1.2/T4 · origin: mmx6 T4

The `-portable` option keeps config and memcards in the run directory instead of ~/.config (reproducible, isolated runs). If you set `PCSX.settings.spu.Speed = 0` in Lua, the emulator runs unthrottled (~150 fps vs ~55).
