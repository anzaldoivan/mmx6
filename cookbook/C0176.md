# C0176 — Empty case 1 plus goto into an if (0) block sets which case cross-jumps
tags: lever,switch,case-tree,cross-jump,goto,block-order · date: 2026-10-10 · phase/task: 1.8.1/T17 · origin: mmx6 W17 rock_07 F50EC

Symptom: retail compiles a switch over {0,2} as a `< 2` compare tree. One case's call cross-jumps with a sibling call outside the switch in the wrong block layout.

Cause: gcc builds the case tree from the case set (an empty middle case reshapes it, C0167). Which arm cross-jumps with the outer call follows basic-block order, not case order.

Lever: add an empty `case 1: break;`. Write the case that must share the outer call as `goto two;` into an `if (0) { two: … }` block. Place the block right after that call, so jump2 merges it there.

Evidence: W17 rock_07 F50EC. The empty case + if(0) goto took isel to 6/65. The C0103 void cast closed the rest (65/65 banked).
Related: C0167 (empty case pivot), C0115 (goto stops cross-jump), C0103.
