# Per-function trial loop in a coder volume: keep the baselines across sync

Problem: `mx.sh sync` wipes the ignored `extracted/` and `expected/` in /work. A fresh `make extract` costs about
5 minutes for each trial.

Move: after one sync, `make extract` and `make build expected`, copy `extracted/` and `expected/` to
`/work/.run/keep` (kept by sync) and restore them after each sync. Another way is to skip sync and tar-copy only
the edited files into /work.

Run `diff.sh` with `--no-pager`, because the image has no `less`. Without it the result prints `DIFF ?`.
A failed hash deletes `build/<bin>` (`.DELETE_ON_ERROR`). Rerun the objcopy step before you diff.
Each coder uses its own `MX6_VOLUME`.

diff.sh overcounts when an earlier function in the same binary changed size, because later addresses shift. Judge
those by the binary sha, or by a byte compare of the function's map extent with jump targets masked.

Evidence: 2.5/T11.c1, c2, c4. Six coders ran in parallel volumes with this loop.

A restored `build/` can fail to link after a sync. splat overwrites `include/macro.inc` and adds `labels.inc`,
`gte_macros.inc` and `include_asm.h`. Without a split run the tracked `macro.inc` is used, and overlays with jump
tables in INCLUDE_ASM functions fail with `undefined reference to .L800…`. Save splat's include files once and
restore them with an old file time (T11.c6).
When a program does not link there is no map for diff.sh. Compare the function in the unit `.o` instead: its
instruction words and relocations, with branch targets taken from the function start (T11.c5, c6). It agreed
with the binary hash on every program.
