# C0051 — Narrowing control from the real population (hide one input dir)
tags: self-test,control,scanner · date: 2026-10-01 · phase/task: 1.5/T3 · origin: T3 optscan

A scanner's narrowing control can reuse its real population. Symlink every real input dir but one into a scratch root. Then require the coverage check to refuse and to name the hidden one. The control needs zero setup data. The real run doubles as the false-positive control.
