# C0110 — Remainder as value minus quotient times divisor, then divide in place, reuses the quotient
tags: lever,divide,remainder,quotient,regalloc,digits · date: 2026-10-03 · phase/task: 1.8/T11 · origin: mmx6 W2

1. **Residual (tell)**: digit or unit conversion (`/100`, `%100`, `/10`) where retail does one divide per step and reuses its quotient, while the draft's `%` emits a second divide or keeps an extra value live, shifting saved-register choice.
2. **Mechanism**: gcc 2.95 does not fold `x % k` into a prior `x / k`; `r = x - q*k` reuses `q`, and dividing `r` in place (`r /= 10`) keeps one pseudo for the tens, so the allocator lands values in retail's saved registers.
3. **Lever**: write the remainder as `value - quotient*k` into the next digit's variable, then divide that variable in place; for time fields `minutes = q60 - hours*60` before `seconds = time % 60`.
4. **Byte proof**: wave W2 (1.8/T11), rock_18:0x800EED18 107 → 156/156, banked; rock_18:0x800EDDB4 365/365 (minutes from the quotient), banked. Levers live by `harvest.py --inert-wave W2`.
