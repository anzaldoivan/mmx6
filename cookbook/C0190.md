# One call per arm instead of a shared argument local before one call

Symptom: arms pick an argument (e.g. 0x10 or 0x20) into a local, then one shared call. The residual is at the argument select or a goto-shared tail out of order.

Lever: write the full call (and tail stores, return) in each arm. The cross-jump of gcc merges the identical call tails into retail's shape itself.

Cases: W20 SLUS_013.95 0x8004EA78 (87/110 → match), rock_04 0x800F351C (per-arm full tail instead of goto shared tail) (T20).

See also: C0138, C0083, C0103.
