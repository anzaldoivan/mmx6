# Call with no arguments where retail sets no argument register

Symptom: a call whose argument register already holds a value from an earlier compare or load; passing that value explicitly swaps registers around the compare.
Lever: declare and call the callee with no arguments (`M2C_UNK f();` + `f();`); when the callee's own definition takes a parameter, call through an unprototyped cast `((void (*)())f)()`, never a `(void (*)(void))` cast: the gate's reconcile refuses the latter as a declaration with 0 params vs 1 (R3, W21 rock_07 F6E78). The unprototyped form is the T21 fix in F6180.c; unconfirmed until F6E78's regate banks.
Cases: W21 rock_09 0x800F32B0 (47 → 52/52), rock_07 0x800F6180 (21/21; its `(void)` cast stopped the F6E78 regate) (T21).
See also: C0103, C0161.
