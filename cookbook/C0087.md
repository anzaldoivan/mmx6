# C0087 — Loop guard: while copies its exit test as the guard; a written guard + do-while keeps yours
tags: idiom,sym-loop-reversed,G-jump,jump,loop,guard · date: 2026-10-02 · phase/task: 1.7/T6 · origin: BFM §279 re-proven

1. **Residual (tell)**: a loop's entry guard is its own exit test (`sltu $2,$4,$3` + `beqz`) where the target guards with a cheaper compare (`blez` on the count), or the reverse; 2 insns. `sym-loop-reversed`
2. **Mechanism**: jump (G-jump). For a `while`/`for` loop jump copies the exit test in front of the loop as the guard and marks the bottom test `NOTE_INSN_LOOP_VTOP`; a `do {} while` has no top test to copy, so the guard is whatever the source writes.

3. **Lever**: `while (p < e) {...}` -> copied guard `p < e`; `if (n > 0) do {...} while (p < e);` -> the source's guard (`blez $5`). a 12 insns, b 10.
