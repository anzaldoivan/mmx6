# C0150 — Split two stores of one table address around the constant stores, and drop the pin
tags: lever,order,store,table,pin,sched · date: 2026-10-06 · phase/task: 1.8.1/T9 · origin: mmx6 W9 rock_22 F461C

Symptom: a block stores small constants and a table address into fields before a call. Retail materialises the constants first and the table address late (in the first argument of the call). The draft hoists the high half of the table address to the top. A hard numeric pin on the table pointer makes it worse. Pure store-order sweeps plateau at 2 rows.

Lever: drop the pin. Write the table address twice, as two separate stores split around the constants. Put the first store after the small constant stores and the second store after the later address stores. Write the constant stores in retail order (the 1-stores before the 6). The longer-lived address then lands where retail has it.

Case: W9 rock_22:0x800F461C (T9.c68, retry of c43 88/90, 90/90). The twin W8 rock_15:0x800EB7E8 (88/90, same 2-row wall) should take it.
Related: C0135 (statement order), C0141 (pins), C0148 (read before adjacent stores).
