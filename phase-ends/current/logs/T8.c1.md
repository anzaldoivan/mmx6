# T8.c1 — PsyQ version scoring of exe lib band + 15 inter-lib gap evidence

Changed (untracked scratch): `.run/t8/psyqscore.py`. Imports `tools/mmx6/boundaries.py` (`programs()[0]` exe image, `load_ghidra`/`ghidra_view`, `load_sigs`, `sig_ok`, `Prog`); boundaries.py untouched. Output: addresses/names/counts only (G12).

Method:
- rows = exe `lib` rows of config/boundaries.txt minus `*/VM_VIB.OBJ` (weak, 2) → R=233.
- agree: row bytes at lo match a same-named LIB/OBJ sig of the version with len == hi-lo (any of duplicate same-named objs).
- placed/unique: per object, 4-aligned lo in [0x80054AD0,0x8006D5D4) with full sig match (anchor = first fully fixed word, indexed; verify with `sig_ok`).
- GAP extent = next non-weak lib row lo; funcs = ledger `vendor:unproven/<tu>` names (all 25 covered; no ghidra-only funcs in gaps); callers = exe jal sites into [lo,hi) classed `lib:<OBJ>` (in a lib row) or `game:<ghidra func>`; sigs grouped per (obj, span) with versions `a+b` or `first..last(n)` (n = count; set may be non-contiguous); hints = plate `Possible X/name` inside the gap.

Run: `bash tools/run.sh t8score -- /opt/homebrew/opt/python@3.14/bin/python3.14 .run/t8/psyqscore.py` → rc 0; log `.run/logs/t8score.log`: 16 SCORE, 15 GAP, `SCORE CONTROL OK`.
