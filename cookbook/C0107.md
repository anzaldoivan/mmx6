# C0107 — If/else stores instead of a ternary end cse path-following so a field is reloaded
tags: lever,ternary,if-else,cse,reload,byte-field · date: 2026-10-03 · phase/task: 1.8/T10 · origin: mmx6 W1

1. **Residual (tell)**: The draft is one instruction short where the target reloads a byte field after a two-way assignment. The draft reuses the value already in a register across the branch.
2. **Mechanism**: This is observed, not source-proven. `x = c ? a : b;` expands to one conditional set that cse can follow through. An `if (c) x = a; else x = b;` with stores in both arms creates a join block. The join block ends cse path-following. As a result, the later field read is a fresh load, as retail has.
3. **Lever**: Rewrite a nearby ternary assignment as if/else stores (both arms storing to the field). Try it at the assignment just before the residual load.
4. **Byte proof**: In wave W1 (1.8/T10), this rewrite closed the last residual of rock_07:0x800F0CF4 → 237/237 (banked). W1 rock_06:0x800EDC9C also closed with if/else-if arms rereading the byte (155 → 237).
