# C0193 — Function-table dispatch as (idx << 2) + base cast to a function pointer, not array indexing

# Function-table dispatch spelled as byte arithmetic, not array indexing

Symptom: a table dispatch `table[self->idx](self)` leaves the index and base registers swapped (register residual at the shift/add).

Lever: spell the address as m2c does: `(*(void (**)(void*))((self->idx << 2) + (s32)table))(self)`. The add operand order follows the source (C0146).

Cases: W21 rock_11 0x800F8064 (45 → 51/51) (T21).

See also: C0146, C0084.
