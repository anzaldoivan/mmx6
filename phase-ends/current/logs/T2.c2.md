## Design notes
- seed candidates = dup-class members ∪ exact twins (twins.jsonl, streamed, filtered by target vram hex), banked =
  corpus c|c-empty or gated registry member; sort (not registry exemplar, prog, vram). Body: registry shared path
  (whole file, reason = registry col 6) else the defining file among declsync.unit_files(prog), function text by brace match.
- open twins exclude gated registry members; `twins <k>` on the CARD line = listed count (≤ 12).
- target.s: include_asm → nonmatchings .s; asm → glabel..endlabel span of the whole-TU .s. scaffold.c = decompile.py
  stdout, else `/* decompile.py rc <k> */` (asm-state functions: decompile.py only finds nonmatchings).
- G44 scan: `\b(L\d{2,}|C\d{4})\b` over card.md (word boundary keeps hex like `0x800C4578` out). Lever ids = valid
  rows of codegen_map.read_rows; cookbook ids = cookbook_check.ROW_RE over cookbook/INDEX.md.
- refusal removes the pack dir; if draft.c/verdict.json exist there, only the card files are removed (never drafts).
- rc: k = 0 → 3 (wins over refusal), refusal → 1, else 0.
- callee prototypes: PROTO_RE (call statements after return/else/goto/case/do skipped) + declsync.definitions; src/ today
  has 1 prototype name, so most callees print `-` (checked on func_800120A0: every callee `-`, none declared in src/).
- banked targets without asm are allowed only by the self-test (`allow_banked`).
