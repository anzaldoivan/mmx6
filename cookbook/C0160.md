# Callee-saved swap among loop invariants: add copies that combine later deletes

Symptom: a loop preheader holds the right invariants in swapped callee-saved registers (regalloc residual, a few words).

Cause: global alloc ranks equal-ref invariants by live length, which follows their preheader order. An invariant that is borderline in loop.c's pass-1 desirability test moves in pass 2 and lands after the others. The test is `threshold * savings * life >= insn_count`, and for such an invariant the `-dL` dump prints "not desirable".

Lever: raise the loop's insn count with copies that combine deletes later. In each arm, route a load or a constant through an s32 local. Then copy it into the narrow target (`t = 0; t2 = t;` / `t = load; t2 = t;`). Diagnose with `cc1 -dL`.

Also: the compiler never hoists a pinned register variable used directly in a loop. Copy it into a plain local in the loop guard so that the compiler hoists its product.

Evidence: W12 SLUS 274A0 (c22 179/184 -> c64 184/184).
