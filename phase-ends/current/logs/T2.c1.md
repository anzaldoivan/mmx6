## Notes for the expert
- Deviation: control draft = m2c scaffold under `#if 0` + the function's INCLUDE_ASM line, so R is a compiled result that reads asm/ through the snapshot's hardlinks (raw scaffold gives nocompile, which a missing-input snapshot would also give).
- cards.py rc 0 on any PACK line (match/fail/nocompile); probe's own `sys.exit` paths give rc 1 without a PACK line.
- /work is left synced and unbuilt by the control (the fleet run after rebuilt it).
- journal `--append` replaces any caller-given prev; refuses if the existing file fails --check.
- generalizable: a snapshot via `cp -al` of read-only trees + copy of the rest isolates a container compile from `mx.sh sync` wipes (sync `rm -rf` only unlinks).
