# A goto inside a macro is marked at each use site of the macro

Problem: `#define SETC(k) { ...; goto set; }` puts a goto at each use. psxd_floor reads
gotos in the cpp output, so it counts one goto at each use site.

Move: put a standalone `// !FAKE: <reason>` line directly above each `SETC(k);` call. A trailing marker on the
macro's own `#define` line covers none of the uses.

Evidence: 2.5/T11.c1, shared func_800EEC50, three gotos through SETC. Marked at each call, goto-unmarked 0.
