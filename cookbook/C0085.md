# C0085 — Spill slots swapped: reload assigns slots in pseudo (declaration) order
tags: idiom,sym-spill-slot,G-alloc,greg,spill,decl-order · date: 2026-10-02 · phase/task: 1.7/T5 · origin: mmx6 repro

1. **Residual (tell)**: a temporary in a spill slot at the wrong offset: two spilled values' `sw $2,<off>($sp)`/`lw` slots swapped against the target, same length. `sym-spill-slot`
2. **Mechanism**: greg (G-alloc). After global-alloc, reload walks pseudos in regno order and gives each one left without a hard register the next stack slot; regno order is expand's creation order, i.e. declaration order.
   - src:gcc-2.95.2/gcc/reload1.c:797 "alter_reg (i, -1);"
   - src:gcc-2.95.2/gcc/reload1.c:2422 "x = assign_stack_local (GET_MODE (regno_reg_rtx[i]), total_size,"
   - a-side `.greg`: spilled 82 84 85 at 48 52 56 (`(const_int 52 [0x34])) 0)`).
3. **Lever**: swap the spilled values' declarations (`int v2, v3;` -> v2 52, v3 56; `int v3, v2;` -> v3 52, v2 56). Which values spill is global-alloc's priority (L05/L06); a spill that should not exist is a register-pressure lead (shorten a live range) or `sym-register-pressure`. Inertness checked: b same length, bytes differ.
