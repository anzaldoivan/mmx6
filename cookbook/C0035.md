# C0035 — A cpp|cc1|maspsx|as pipe returns only as's rc; a dead cc1 still exits 0
tags: make,pipefail,toolchain,psx · date: 2026-10-01 · phase/task: 1.4/T1 · origin: mmx6 T1

A pipe's exit status is its last stage's. With `cpp | cc1 | maspsx | as` a crashed or missing cc1 still yields rc 0 and an empty object. Run the pipe under `set -o pipefail` or assert the expected symbol with `nm`.

Source: phase 1.4 T1 (toolchain smoke loop).
