# Scratch script against container-only build state: run it inline, never pull build/

Problem: a one-off script needs the container's build/ (corpus, elf, sig). `mx.sh pull build/...` is refused, because the firewall purges build/. `mx.sh sync` wipes /work except .run and waves, so the build is gone after a sync.

Move:
- Keep the script on the host (scratchpad) and run it in place: `bash tools/docker/mx.sh run python3 -c "$(cat <script>)" <args>`.
- Run it after the fleet, with no `mx.sh sync` between. Write its tracked output to a path under config/ or docs/ and `mx.sh pull` that path.

Example: 2.5 T5.c4 wrote config/types/fields.tsv from the census this way.
