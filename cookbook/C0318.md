# C0318 — Member widths via sizeof in the cc1 offsetof table

# Member widths from the same cc1 offsetof table

Problem: a field table needs each member's width as the pinned compiler lays it out, not a hand count. C0260 gives offsets only.

Move:
- Reuse the C0260 table (`x4names.offsets`, which emits `(int)&((T *)0)->FIELD + 1`) and pass as the field text `m * 0 + (int)sizeof(((T *)0)->m)`.
- The cast and `&` bind tighter than `*`, so `&((T *)0)->m * 0` is 0 and the `.word` is sizeof + 1. Subtract 1 as for offsets.
- Bitfields have no sizeof: keep C0260's `-` for them.

Example: tools/mmx6/objfields.py `--check` (2.5 T5.c4), 121 members of include/mmx6/object.h.
