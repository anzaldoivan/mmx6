# Callee-saved register swap of a loop counter: a top-tested loop with no if guard

Problem: a loop counter and a cursor swap two callee-saved registers (56/62). The source is
`i = 0; if (n != 0) do { call; i++; cur += 16; } while (i < n);`. Declaration order, statement order,
`register`, init moves and shorter live ranges all leave the swap. The swap is not a tie: the counter loses.

Lever: write the inner loop top-tested, with no written guard. The counter gets priority in global alloc.
- `for (i = 0; i < n;) { call; i++; cur += 16; col += 16; }`, or `while (i < n) { ... }` with i set before.
- Keep the increment in the body, ahead of the other steps. `i++` in the for header also fixes the registers,
  but it is scheduled into the load delay slot (34/62).

Check: the probe diff. C0087 is the opposite case (a written guard plus do-while keeps your own guard test).
Related: C0087 (loop guard copy), C0375 (score the unpinned draft first, then depin).

top-tested form on their own, which replaces the seed's `$18` register pin (pin 1 -> 0, 62/62).
