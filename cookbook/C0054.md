# C0054 — Self-test controls inject disagreements, never borrow real ones
tags: self-test,control · date: 2026-10-01 · phase/task: 1.5/T5 · origin: T5 bound2 ledger

A self-test control that borrows a real disagreement breaks the day the real run reaches 0. Inject a synthetic disagreement instead, so the control stays valid when the population is clean.

Source: phase 1.5 T5 (bound2 ledger control).
