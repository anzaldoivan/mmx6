# Pin a Docker image by config digest, not image Id, under buildx

- Symptom: the output of `docker image inspect --format '{{.Id}}'` changes between identical builds, or it differs from what another host reports.
- Cause: the buildx/containerd image store wraps the image in an index with attestation manifests. The Id can be the index digest.
- Fix: pin the base by `FROM image@sha256:<manifest digest>`. Record the config digest of the built image (`.Config` blob digest) as the reproducibility pin. Keep the Id only as an informational line.
