# X4 names for shared X6 code

Generated by `tools/mmx6/x4names.py --doc` from `config/x4/names.tsv`. Never hand-edited.

Each row is an X6 address with a real name from sozud/mmx4 (AGPL-3.0, pin `807a01b`). A `gate` or `bytes`
row is an X6 function of 8 words or more. Its compiled body equals an mmx4 function under X6's compiler.

That function is its only partner, or one of partners that all carry one name (`same-name <n>` in the basis).
Otherwise it is the one partner the relocation slots of other aliased functions point at (`slot <n>`).
The name is an alias: a search key for the X6 address, not a symbol. Prior-art row: `docs/prior-art.md` L5a.

- tier `gate`: the X6 function is banked in C (proven-at-gate).
- tier `bytes`: the signature is exact and the body is still assembly (consistent-with-bytes).
- tier `slot`: a lead, not a proof. Two or more aliased functions reference this address in the relocation
  slot where their mmx4 twin references that symbol, and none says otherwise. Votes are agree/disagree.
- scope `object`: the mmx4 source is one object's file. Identical bytes do not prove the same role. The
  name stays an alias until a role basis exists. Scope `engine`: everything else.

`X4NAMES 246 rows; gate 201 bytes 19 slot 26; engine 85 object 160; func 239 data 7`

Lookup: `python3 tools/mmx6/x4names.py --who <alias text | func_8XXXXXXX | PROG:0xVRAM>`.
