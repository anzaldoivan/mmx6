# Clear loop counted as an explicit down-counter to -1, not while (k--)

Symptom: a fixed-count clear/scan loop over N slots scores far off (counter shape and register assignment) when written `k = N; while (k--)`.
Lever: `for (k = N - 1; k != -1; k--)`, the explicit down-counter ending at -1.
Cases: W23 SLUS_013.95 0x8002C530 (10/24 → 24/24) (T23.c49).
See also: C0077 (down-count for bgtz/bne), C0121 (loop direction sets register order).
