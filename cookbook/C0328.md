# Byte baseline for a refactor without git stash

When: a coder's uncommitted edits must be checked byte-for-byte against HEAD and stashing is off-limits.
- Copy the HEAD versions of the changed files into `waves/<tag>base/` (`git show HEAD:<path>`), `mx.sh push` it.
- In the container: `cp -R waves/<tag>base/. .`, `make extract build`, copy the build to `.run/<phase>/basebuild`
  (survives `mx.sh sync`).
- Sync the edited tree, `make extract build` (build needs extract after a sync), copy basebuild to
  `expected/build` (objcopy the elf if SLUS was deleted), then `tools/mmx6/diff.sh <func>`.
- Per-variant loop: `make build/src/SLUS_013.95/<unit>.c.o` and objdump the function against basebuild's .o.
