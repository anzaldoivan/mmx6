# Gate clang-format reflows debt markers and bare macro bodies
- The gate runs clang-format on drafts before compiling and banking, so text the gate or a later lint must see can be reflowed.
- Put any marker a later lint must see (pin reason, FAKE) on its own line above the code, never as a trailing comment.
- A goto-unmarked floor needs a standalone marker line with a non-empty reason. A marker with no reason counts as unmarked.
- A regate copy that carries a trailing pin reason gets wrapped and fails pin-unmarked. Re-run the standalone marking step on regate copies.
- A per-member copy of a shared body inherits the unmarked pins of the exemplar. Each copy must mark them as inherited from its exemplar.
- A macro used as a bare if body can be reflowed into different code. Brace every macro use.
