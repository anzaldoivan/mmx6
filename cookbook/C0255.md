# Mark debt constructs on clang-formatted text, never before format

Problem: a `// !FAKE:` marker written above a construct can stop covering it after `make format`.
clang-format `InsertBraces` rewrites `if (x) goto l;` into `if (x) {\n    goto l;\n}`.
A standalone marker above the `if` line then no longer sits directly above the `goto` line.
psxd_floor counts that goto unmarked.

Move: run clang-format first (`--style=file --assume-filename=src/<x>.c`), then insert markers, then format again
and re-count with psxd_floor (`marked(raw_keywords(t), markers(t))`, keys ending `-unmarked`). Markers are always
standalone `<indent>// !FAKE: ...` lines (never trailing: C0218, trailing ones are reflowed away near column 80).

Evidence: 2.1/T1 propagate.py inherited_control. Marking the unformatted planted body left 1 unmarked after format.
Marking the formatted body left 0 after a second format pass. propagate.py tudecl_step already formats first (gm.fmt).
