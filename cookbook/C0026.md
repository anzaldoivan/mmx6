# C0026 — Ghidra may emit switchdataD_ labels every 8 B inside one switch table; merge labels within a bounded table
tags: ghidra,switch,jump-table,labels,boundaries · date: 2026-10-01 · phase/task: 1.2/T8 · origin: mmx6 T8

Ghidra can label one large jump table with a `switchdataD_` label every 8 bytes. When counting tables, bound each by the dispatch's `sltiu` limit and treat labels inside that byte range as one table. Ghidra's `Address table[n]` count is advisory and can overrun into the next table.
