# Gate declaration check is program-wide: fix every sibling prototype
- The gate's declsync (R2/R3) checks the banked signature against every prototype in the whole program.
- So carving into a new unit does not dodge an `M2C_UNK func_X();` vs `void` conflict.
- Fix: rewrite the sibling prototypes (grep src/<prog> and include/) to the banked return type.
- Keep old-style `()` so call sites with any arg count still compile. Check that no caller uses the result.
- Trap: a prototype with a trailing `/* extern */` comment changes alignment: `make format` then pull, else the
  fleet's format-check fails.
