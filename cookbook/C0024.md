# C0024 — Ghidra BinaryLoader headless -loader-baseAddr can leave image_base 0. Import at 0 and setImageBase in a preScript
tags: ghidra,binaryloader,image-base,headless,overlay · date: 2026-10-01 · phase/task: 1.2/T7 · origin: mmx6 T7

A headless import of a raw overlay with `-loader BinaryLoader -loader-baseAddr` left image_base at 0. The reliable path is to import the overlay at base 0. Then a preScript calls `currentProgram.setImageBase(base, true)` before the analysis.
