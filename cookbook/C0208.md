# Constant-address view macro at each access, not an extern symbol or a cached pointer local

- Symptom: a fixed-address counter read and written through an extern symbol splits the address build. The residual is large and positional.
- Cached pointer locals for an object's pointer fields scored 5/79 on SLUS 2DFA0.
- Lever: access the counter through a view macro such as `#define D_801F6000 (*(s32 *)0x801F6000)`. A table at a fixed address becomes a raw constant base.
- Re-read an object's pointer fields through a view macro on the void pointer parameter at every use. gcse then reproduces retail's copy and register order.
- `#undef` the macros at the end of the function.
- Cost: the banked body carries no relocation for that address. Its census dup key then differs from the asm row.
- `propagate.py --check` then reports `REGISTRY refused drift`. Re-key the registry row to the built key. The binary stays byte-identical (W27 SLUS 21500).
- The macro is also `address` readability debt.
- Seen W27: SLUS 21500, 2DFA0. Related: C0105, C0178, C0189.
