# C0041 — splat's instruction comment word is in file byte order. Decode as little-endian before field extraction
tags: splat,mips,decode,endianness · date: 2026-10-01 · phase/task: 1.4/T5 · origin: mmx6 T5

The hex word that splat writes in each asm line comment is the file's byte sequence, not the instruction value. On PSX (little-endian), byte-swap the word before you extract the opcode/register fields.

Source: phase 1.4 T5 (optscan.py, c1 deviation).
