# Survey a platform port against the PSX image without a disassembler
When: a port of the game to another platform exists. The questions: is it the same code base, has it symbols, does its layout match ours?
1. Read the PE header and the Rich header. Note the linker version and the product ids with object counts. C objects approximate translation units.
   A CodeView record in the debug directory means a PDB existed. Also check the data directories (exports) and the imports.
2. Classify ASCII runs of 6+ bytes by kind: format, path, API, runtime, pdb. Record counts only, never text (G12, M16).
3. Hash every 32-byte window of the port, at all offsets, into a set. Slide each PSX program (exe, each overlay) at 4-byte steps.
   Skip windows with fewer than 10 distinct bytes. Count hits and runs. Pointer-free tables match verbatim.
   Pointer-bearing data cannot match, because the address width differs.
4. Map the start of each hit run to its port offset. Count the steps where that offset increases.
   A high fraction means data order and table extents carried over (mmx6 2.2 T8: 92-95%).
5. Hash each 2048-byte sector of both data archives. The shared-sector count tells a re-pack from a rebuild.
6. Function pairing needs disassembly and data xrefs to the shared tables. An xref to the archive path string finds only the platform file open.
Cost: about 2 min of Python for a 1.8 MB exe and 1 MB of PSX programs. The scripts are scratch.
