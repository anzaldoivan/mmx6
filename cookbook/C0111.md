# C0111 — If/else arms each storing a field via a pinned block local cross-jump into one store
tags: lever,if-else,cross-jump,jump2,delay-slot,clamp,register-pin · date: 2026-10-03 · phase/task: 1.8/T12 · origin: mmx6 W3

1. **Residual (tell)**: a clamp/select that stores one field from two arms; retail has the constant arm in a branch delay slot and a single shared store with the value in the return register, the draft presets the value then overrides it and stores once from another register.
2. **Mechanism**: observed, not source-proven. `x = v; if (c) x = K; p->f = x;` (or a ternary) folds to preset-then-override, so there is no arm to steal into the delay slot. Two arms that each store the field themselves, with the value in a block-scope register-pinned local, stay separate until jump2 cross-jumps the identical store tails into one, leaving the constant load where reorg can fill the delay slot.
3. **Lever**: write the clamp in its own block: `{ register s32 m asm("$2"); if (v >= 6) { m = v; p->f = m; } else { m = 5; p->f = m; } }` (pin the register the retail store uses); keep both arms' stores textually identical so they merge.
4. **Byte proof**: wave W3 (1.8/T12), rock_02:0x800F0F4C 61/64 → 64/64 (banked).
