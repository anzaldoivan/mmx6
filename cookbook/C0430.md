# A probe-matched wave draft goes stale: re-probe and re-spell before banking

- Context: drafts in `waves/W*/` scored N/N weeks before the bank. Struct members were named since then. Example: commit 2412e430 renamed `unk68`/`unk70` to `terrain_box`/`collision_flags`.
- Symptom: bank.py stops R1/R2 (does not compile) on a draft whose journal score is N/N.
- Fix: rename stale `unkNN` members to the homed names (config/types/fields.tsv or the header). Then re-probe. Codegen is unchanged.
- Two drafts banked into one unity TU can declare the same extern differently, `(void)` vs `(struct X*)`. Use the TU's own form. Here it was the unprototyped `void f();` that the existing call uses.
- Put `#undef` for any body-local macro at the end of the body.
- Evidence: 3.0 T2.c1, func_8002E974 (W7) and func_8002F06C (W17), both DIFF 0 after the respell.
