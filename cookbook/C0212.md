# Pinned pointer base added index-first: write `b -= -i`

Symptom: a byte table is read at `sym+K` through a pinned pointer local `b` (shape below). It matches except one row.

```c
b = (s8 *)&D; b += i; v = b[K];
```

The row-base add takes the index as its first operand. Retail takes the base first.
cse canonicalises `(plus base index)` to index-first. W46 tried about 60 variants that all stayed index-first.
They included member arrays, 2-D views, `b = i + b`, `&b[i]` and struct pointer locals.
A base copy with a dead store (C0202) and an s32 offset local (C0210) failed too.

Lever: subtract the negated index from the pointer: `b -= -i;`. The add comes out base-first with no other change.
This is C0146 (negated subtract for an accumulator) applied to a pointer base.

Related: C0146, C0202, C0210. Origin: W46 SLUS func_8001A4FC (c34 narrowed retry after c16 28/29).
