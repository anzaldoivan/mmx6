# Abs folded into the range compare as a ternary when the constant lands in the branch delay slot

Symptom: `v = abs-ish(x); if (v <= K)` (m2c abs-then-compare) scores a near match. The compare constant's load sits in the branch delay slot instead of the load delay.
Lever: use one expression, `if ((x < 0 ? -x : x) <= K)`. A numerically pinned constant local did not move it.
Cases: W23 rock_10 0x800F990C (45/47 → 47/47) (T23.c48).
Contrast: C0144 (a range test where the ternary folds to a negate: nested ifs), C0164 (abs inside a divide).
