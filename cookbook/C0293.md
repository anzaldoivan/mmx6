# C0293 — Bank-path locator calls from a snapshot or tree copy pass root=os.getcwd(), not layout.ROOT
tags: layout,locator,snapshot,cwd,bank,gate,propagate · date: 2026-10-31 · phase/task: 2.4/T5 · origin: mmx6 T5.c1

`layout.ROOT` is the repo checkout. gate.py banks inside a snapshot cwd. propagate.py dry-runs in tree copies.
A locator call with the default root reads the REAL tree, not the copy under test. The R2 step would edit it too.

Rule of thumb: every bank-path call into layout.py passes `root=os.getcwd()` (or the copy's root) explicitly.
This covers `find_asm`, `locate`, `Tree` and `role_tree`. Returned paths are repo-relative: join them to that root.

Cost note: `find_asm` and `placed` build a `layout.Tree` per call, which parses all of the program's units.
That is fine for self-tests. Cache one Tree when a loop calls them per function.
