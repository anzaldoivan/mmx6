- Makefile: BINS = config/*.yaml; split = per-bin stamps build/split/<bin>.stamp (parallel); `build: split` then sub-make (build waits for split under -j); pattern rules build/%.elf (.SECONDEXPANSION), static build/<exe>, build/rock/%.bin, each ends in `sha1sum -c config/check.<bin>.sha`; build/%.bin.o (.incbin); .SECONDARY (objects were being deleted as intermediates).
- docs/memory-map.md: "Overlay builds" section.

## Walls hit and levers (all overlays are one asm TU: data words reach gas as code)
- gas -march=r3000 rejects rabbitizer R3000GTE decodes of data words (dsll32, tge*, ll, sync, sdc1 ...; 24 errors over ~22 overlays). rabbitizer reports them isValid. Lever: overlay objects `-march=r4000` (pattern-specific ASFLAGS).
- splat split overwrites include/macro.inc in the container and pulls include/gte_macros.inc, which defines a GTE `ll` macro shadowing MIPS `ll` ("too many positional arguments", rock_03 0x800F7CE8). Lever: overlay .s piped with `.include "macro.inc"` + `.purgem ll` prefix. (Tracked include/macro.inc differs from what splat writes; pre-existing, not touched: include/ out of scope.)
- Debian binutils inserts `sync` before every `ll` (loongson3 llsc fix) → rock_03 4 bytes long, first diff +0x8F30 (shifted %lo). Lever: `-mno-fix-loongson3-llsc`.
- Link: 22 overlays had undefined D_<addr>/func_<addr> (55 names) — refs into the overlay that splat counts as defined but never labels, and j/jal targets like 0x88040010 never listed. Lever: per-bin build/<bin>.provide.ld = `PROVIDE(name = 0x<addr from name>)` from `nm -u` of the bin's objects.
- Parallel splat: every run rewrites include/macro.inc etc. with identical content; assemblers start only after all splits.

## Commands
- `bash tools/docker/mx.sh sync && bash tools/run.sh --bg t5c1 -- bash tools/docker/mx.sh run sh -c 'make extract && make clean && make -j8 split build health'`; wait → exit=0, `grep -c ': OK$'` = 57, `BOUNDARIES OK 57 programs`, wall ~30 s (timed from after sync to wait return).
- rerun `make -j8 split build` → nothing to be done (stamps + .SECONDARY).
