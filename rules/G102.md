# G102 — License firewall for prior art: facts only, mmx4 C only when proven shared
id: G102 · group: G · status: active · tags: license, prior-art, provenance · origin: intake · added: 2026-10-01

## Text

Nothing — a file, a function body, a table, a header or prose — is copied from a source whose license does not permit
it. Kuumba123's repositories (no license) and MegaManX6Recomp (PolyForm Noncommercial; its generated C is never an
input) contribute facts only, re-expressed in our own code and words and credited in `docs/prior-art.md`. C from
sozud/mmx4 (AGPL-3.0) is adapted only for a function a signature scan proves shared with X6's bytes; the adapted file
keeps its attribution and license, is listed in `THIRD_PARTY.md` with the source commit, and banks through the byte gate
like any other draft.

## Why

The repository is public from the first commit and AGPL-3.0; a contaminating copy is a full-history rewrite, the same
class of cost as a committed ROM byte (DK-1).
