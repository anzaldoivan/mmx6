# Never name a shared-body exemplar from one member's use

A function under `src/shared/entity/` (e.g. `state_dispatch.c`, func_8003744C + D_80073C1C) is the template that hundreds of members' name `#define`s point at (C0065). Naming it after one system's role (ladder) renames the template for all 416 members. Hold it with clause `shared-body exemplar: name must fit every member`, or name it for the shared mechanism only. Check `grep -rl <token> src/shared` before admitting a name for a use-only token. (2.6 T14.c3)
