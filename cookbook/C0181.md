# Equality chains on a byte: one early return per value keeps retail's beq chain

Symptom: retail tests a byte against several constants with one beq each. The draft compiles to an unsigned range test
(`sltiu`) or a case tree.

Cause: gcc folds `k == 0x2D || k == 0x2E || k == 0x2F` and `t != 4 && t != 5` into range compares. A dense 3-case switch
still compiles as a case tree (slti pivot).

Lever: write one `if (k == K) return;` per value (or `if (t == 4) return;` then `if (t != 5) ...`). Use if/else-if for a
linear chain (confirms C0113). A switch makes it worse.

Origin: mmx6 W18 SLUS_013.95 func_8003DD6C, also rock_08 (W18).
