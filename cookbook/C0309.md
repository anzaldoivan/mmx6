# C0309 — Whole-name stem rule: only for stems a fixed system list holds
tags: layout,propose,stem,glossary,system,slus · date: 2026-10-31 · phase/task: 2.4/T24 · origin: mmx6 T24.c1

Context: `layout.py propose` skips token 1 of a function name as a verb
(`wait_for_file_load` -> `file_load`). Names like `memcard_format` or `task_yield` lose their meaning that way.
A rule "the whole name is a glossary stem -> it is its own stem" seems natural. But the glossary holds many
whole-function rows (start_player_attack, play_sound, update_player). On SLUS_013.95 the rule sent 59 functions to
stems no system held. Propose refused them.

Move: scope the whole-name rule to the stems of a fixed list. When a name is itself a stem that a `## SLUS systems` row
of docs/layout.md holds, use it whole. Otherwise apply the verb skip. Never add system folder names as glossary Terms
rows: they become stems and steal matches (`file` would take dat_file).

Check: diff propose output against HEAD: 0 changes outside the program, and only the weak names change system
(2.4 T24: 6 changes, 0 same-system renames).
