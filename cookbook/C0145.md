# Store a computed byte to its field, then re-read the field at each later use instead of a local

Symptom: retail masks or reloads a byte value after storing it (a fresh load from the field at each use);
the draft holding the value in a local keeps it in a register and drops the reload or the mask.

Lever: store the value to its field once, then write every later use (an index, a call argument plus an
offset) as a read of that field, not of the local. The store/load through the object is what retail
compiled; cse cannot forward the stored value across the intervening call or aliasing store.

Case: W7 rock_22:0x800EF5B8 (T7): table byte stored to field 0x88, the 0x54 pointer index and the
call argument re-read it. Related: C0107 (stores that force a reload), C0139 (aliasing decides moves).
