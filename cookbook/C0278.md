# git add a moved/renamed source before regenerating badges or the debt baseline

Problem: after `rename.py` moves `src/<prog>/func_<addr>.c` to `<name>.c`, `make badges` and
`psxd_floor.py debt --update` read the tree through `git ls-files`. The new file is untracked, so it is skipped.
Symptom (2.3/T8.c1): extern 15714 -> 15712, finished 4781 -> 4780 — counts fall for a byte-neutral rename.

Move: `git add <new path>` (and `git rm --cached <old path>`) first, then `make badges`, `debt --update`,
`badges --check`. A rename should move only placeholder / placeholder-use / filename counts.
