### Group 1 expr/cse (cse_expr.md)
1. Cross-call VALUE CSE (§3, :203-222). Tell: extra callee-saved reg, tail recomputation (e.g. andi) reuses $sN. Mech: cse.c pseudo classes survive calls (invalidate_for_call kills hard regs only; cse.c:1756 [2.8.1 pm]). Lever: `__asm__("" : "=r"(x) : "0"(x));` between the two uses. Proof: func_80176D94 (toolkit). Repro: f(x&0xffff); g(); use x&0xffff.
2. Cross-call ADDRESS caching (§2, :136-199). Tell: `addiu $s0,$sp,K` once plus `move $aN,$s0` per call, vs target per-site `addiu $aN,$sp,K`. Mech: calls.c:1632-1650 [2.8.1 pm] forces a pseudo per &local; cse merges; global.c gives it an $s reg. Lever: nested-block `void *q=&buf; f(q); asm volatile("" : "=r"(q));` and last use bare &buf. Proof: MATCH func_80149374, func_801493D0 (23 ins). Rules: output-only, volatile, no function-top init, kill after every site except the last. Caveat [A23-2]: a multi-reg class (e.g. an added aggregate copy) defeats it; mips.c:2350 expand_block_move copy_addr_to_reg. Repro: two locals, f(&a,&b); g(&b).
3. `/s` MEM_IN_STRUCT_P aliasing (§4, :226-291). Tell: zero-offset ptr load stuck under a fixed-symbol store while member loads float. Mech: expr.c INDIRECT_REF/COMPONENT_REF setters ([2.8.1 pm] 5506-5535, 5891, 4292); consumers sched.c:830/862 [2.7.2] true/anti_dependence, memrefs_conflict_p :628. Repro: load via p, store to global, load via p+4; a/b = member vs cast form.
4. CSE store-side flush (§4b table, :269-283). Tell: global reloaded after `*p=` but not after `p->f=` or `p[k]=`. Mech: note_mem_written -> invalidate_memory (cse.c:7709/1732 [2.8.1 pm]); bare `*p=`, any u8 store through a pointer, and BLKmode stores set all=1. Lever: pick bare-deref vs member/indexed store. 5. Label/diamond flush antidote (§H.1, :387). Tell: target recomputes `&g+k` per use where ours folds. Mech: find_best_addr fold; cse.c:8430 [2.7.2] new_basic_block after a barrier-preceded label. Also -O2 follow-jumps extends the table across a join (cse.c:8118, :8150 [2.7.2]; toplev.c:3389-3390).
6. Dead-branch retention (§H.3, :389). Tell: target keeps a branch cse proves dead. Mech: record_jump_equiv cse.c:7511 [2.7.2]. Lever: an identity-asm second set of the value. Not byte-named.

3. L3 reversal (:178-209). Tell: `li N-1` ... `addiu -1; bgez` and a REG_NONNEG. Mech: check_dbra_loop :5655, reversal :5750-5900. 4. L4 hoisting (:214-262). Tell: la/lui+addiu in the preheader (moved movable); in-loop `la` at a call-arg = single-use substitution (scan_loop:735, only if loop_has_call). Lever: a call in the loop blocks load hoisting EXCEPT const/RTX_UNCHANGING_P (invariant_p :2760-2775; byte-proven `int t(const int*p,int n){int s=0,i;for(i=0;i<n;i++){s+=*p;f(i);}return s;}` gives lw in preheader). 5. L8 increment position (:308-323). Tell: elimination/reduction differs from sibling. Mech: not_every_iteration set after ANY label or jump in 2.7.2. Lever: where `p+=K`/`i++` sits relative to branches and `continue`. Source-pinned only.
