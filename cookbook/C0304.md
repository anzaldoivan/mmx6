# C0304 — Re-apply a layout on a split program: flatten L-B units (origin map), reuse names, marker-idempotent repoint
tags: layout,reapply,flat,repoint,moves,idempotent · date: 2026-10-31 · phase/task: 2.4/T15.1 · origin: mmx6 T15.1.c1

Context: layout.py Flat (2.4 T15.1.c1), the redo of a pilot regroup with new naming rules.
- Read every unit with its role `.c` includes inlined. Rebase relative includes and put a blank line between roles.
- Keep `origin[unit]`, mapping each virtual line to (path, line). Plan and build run on this flat view in retail order.
- Old role names of the applied program may be reused, so they are left out of the taken set.
- Old files that no run reaches are deleted. Mirror the deletions on the host (C0299).
- Moves rows are split by origin, so repoint maps every old (path, line).
- Tag moves rows with the applying program. Append a `# repointed` marker after repoint.
- Repoint reads only rows after the last marker, so a second run maps 0.
