- In place, a body in the middle of a role file stops at R4 `foreign-rodata`, and carve.py refuses a mid-file cut for it alone (C0360).
- Move: `carve.py opt <prog> <tu> <file start>`, then `carve.py opt <prog> <newtu> <next file start>`, so the role file is one unit. Then the gate's rodata step places the table and the body banks (T26.c2: func_80040FB4 in 80040388.c, func_80050670 in 8004FF7C.c, 204 rodata bytes).
- After a rodata-step bank, the next `propagate.py --check` shows `drift` and `not in class` for rows whose key moved with the carve. Re-key them to the built key (campaign.md T44 binding).
- SLUS unit 120A0 is the exception: see C0385.
