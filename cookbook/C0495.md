# A refusecause series runs after its fleet with no mx.sh sync between: sync voids the fleet's labels

Symptom: `refusecause.py --prog P` on a freshly fleeted volume gives `R5 link: undefined reference to .L<addr>` rows
(3.3 T6.c1: rock_36 43 of 47 rows, `.L800FEA50`), the false refusals of C0490.

Cause: the runner synced before each step. `mx.sh sync` mirrors include/ from the host, so the generated
`include/labels.inc` vanishes and the tracked macro.inc returns (C0433, C0452). The split stamp survives, so nothing
regenerates them. This is the mechanism C0490 left unproven.

Move: per lane, `mx.sh sync` once, then `make fleet` (FLEET 57 of 57), then every refusecause step with no sync
between. Count `.L` rows per program output: any is a rerun after a refleet, not a cause.

Evidence: 3.3 T6.c1 on mmx6-t6b. The rerun after refleet, with no per-step sync, gave rock_36 43 stale + 4 declaration, 0 `.L`.
