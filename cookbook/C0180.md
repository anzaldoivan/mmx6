# sym+K row base kept split by an s32 offset local; per-arm loop body as a macro argument

Symptom: retail keeps `lui/addiu sym; addiu +K` (an add on the table register) inside or before a loop; the draft folds it into one `lui/addiu %lo(sym+K)`.
Cause: `sym + K` folds at expand time; cse barriers do not split it.
Lever: put K into an s32 offset local in the loop body: `off = K + i*4; *(T*)((s8*)sym + row*S + off)`.
Two arms of one shared macro may need different offset-local terms (`row*S + K` vs `K + i*4`) because loop.c's hoist
threshold (`threshold * savings * life >= insn_count`, T = 58 measured for that TU) differs per arm: pass the loop body
as a macro argument so each arm keeps its own spelling. Which terms the local holds decides whether the divide magic
constant gets hoisted.
