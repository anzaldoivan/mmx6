# C0050 — Coverage oracle: closed set of uncovered-byte kinds with precedence
tags: oracle,coverage,corpus · date: 2026-10-01 · phase/task: 1.5/T2 · origin: T2 corpus spans

A coverage oracle must give uncovered bytes a closed set of kinds with a fixed precedence (here jtbl > libgap > data > pad) and refuse any other uncovered byte. A permissive "data" kind needs its own guard (e.g. a 0-function program is refused), or a regression that turns code into dlabel data passes silently.
