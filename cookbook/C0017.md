# C0017 — analyzeHeadless exits 0 when a script prints an error and returns. Grep the script's error marker
tags: ghidra,headless,exit-code,wrapper · date: 2026-10-01 · phase/task: 1.2/T3 · origin: mmx6 T3

A GhidraScript that prints an error and returns does not change the exit code of analyzeHeadless (0). Wrappers must have scripts print a fixed marker, for example `MMX6ANN ERROR`. Wrappers must grep the log for the marker to set rc.
