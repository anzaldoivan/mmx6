# make format splits a long INCLUDE_ASM line and carve then drops its asm

`make format` splits an `INCLUDE_ASM(...)` line over 80 columns onto two lines. carve.py:44 `INC_RE` matches one
line only. The function's asm goes missing and fleet falls (2.3/T10.c2: 55 of 57).
Fix: keep the line whole inside a fence:

    // clang-format off
    INCLUDE_ASM("asm/...long path...", func_name)
    // clang-format on

Seen on files that already failed format-check before the task. A first `make format` over a red tree reflows them.
After any repo-wide `make format`, check `git diff` for split INCLUDE_ASM lines. The check prints nothing when
clean. Each line it prints is an unclosed `INCLUDE_ASM(`, so a split one:

    grep -rnE 'INCLUDE_ASM\([^)]*$' src/

Clean on the tree at 2.3/T19 (2026-10-30). Run it before the fleet, not after a red one.
