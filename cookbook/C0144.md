# An abs() ternary in a range test folds to a negate: nested ifs with a goto to a shared label

Symptom: a distance test `if (abs(d) < N) call();` (or `(d < 0 ? -d : d) < N`) scores short; retail
tests the sign first and compares each side against N with its own branch, both reaching one call.

Lever: write the two sides as nested ifs that jump to one shared label:
```c
if (d >= 0) { if (d < N) goto near; }
else if (rev < N) { near: call(); }
```
where `rev` is the reversed difference spelled as retail computes it (not `-d`). The ternary or
abs macro lets gcc fold the negative arm into a negate and one compare.

Case: W7 rock_08:0x800EAC90 (T7, 154/154), with the compare written field <= global for load order.
Related: C0115 (goto into an arm body), C0107 (if/else instead of a ternary).
