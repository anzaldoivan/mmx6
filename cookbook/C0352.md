# Reach a mode through its source global, held across the init frame

Problem: a state needs a mode (mmx6: the armor) whose live-object poke breaks the game (C0351: overlay not loaded, stale dispatch).

Move:
- Find in our C where init copies the mode from a global. In mmx6, `func_8003D718` reads the armor from `g_playthrough_state`+0x5E (0x800CCF2E, src/SLUS_013.95/8003D598.c).
- Poke that global from a frame before init. Hold it (rewrite it every frame) until after the init frame. The game then loads its own overlay and code.
- In mmx6 movement.lua, a numeric poke field is an absolute u8 address. The 5th poke element `hold` is the last frame.
- Prove it with four checks. A PC probe on the init function dates the init after the hold start. The live field reads the new mode. Dispatch bad=0. The C0316 control passes.

Example: tools/mmx6/redux/inputs/mv_hover2.lua, mv_ceiling2.lua (armor 4, 2) (2.6 T6.c2).
