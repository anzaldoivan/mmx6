# A placeholder raise: the developer runs it in their own shell, then commits right away
- `psxd_floor.py debt --raise` refuses inside Claude Code: `DEBT FAIL a raise is the developer's act, not an agent
  session's (CLAUDECODE is set)`. No agent or coder can run it. Do not unset CLAUDECODE.
- An unstaged raise line in `config/debt-baseline.txt` is lost when any `commit_task.sh` runs before the bank commit.
  In 2.6/T9 the developer's raise vanished after two router commits. The likely cause is commit_task.sh:121, which
  rewrites the baseline from the staged tree. This cause is not confirmed.
- The commit gate refuses it too. `GATE FAIL raise: ... is new, and this is an agent session (CLAUDECODE is set)`.
  The developer writes the raise line and commits it from a terminal. An agent cannot commit it after them.
- So hand the developer one terminal line: raise, `psxd_floor.py debt`, then `commit_task.sh` with the bank paths and
  `config/debt-baseline.txt`, all chained with `&&`. Keep the green tree untouched until then. Then `mx.sh sync`.
- 2.6/T9 result: developer commit 4f89bc728, 61 files, GATE OK.
