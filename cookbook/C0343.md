# An s8[N] member read as s16 per index: retype the member s16[N/2]

Retail reads a 16-bit value per index from a member the header types as bytes (`s8 weapon_energy[0x10]`).
- Cast forms (`((s16*)p->m)[i]`, `*((s16*)p->m + i)`, `(char*)p->m + (i << 1)`) each leave the `addu` operands
  swapped (`addu v0,v0,s4` vs retail `addu v0,s4,v0`): 2 lines.
- A local `s16* e = (s16*)p->m` hoists the member address: worse.
- Retype the member `s16 m[N/2]` and write `p->m[i]`: 0 lines. Other readers that cast the member keep matching.
Check the field table row (width in bytes is unchanged) and the fleet.
