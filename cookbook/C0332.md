# C0332 — Hoisted externs: every role-file chunk includes the header itself, not once per file
tags: extern,header,hoist,role-file,chunk,self-test,gate · date: 2026-11-02 · phase/task: 2.5/T10 · origin: mmx6 T10.c4

Problem: hoisting `extern` lines into a header (T10.c1/c2) left one `#include "mmx6/globals.h"` per role file (chunk 1). Gate/bank self-tests and carve cut single chunks (C0313: `#include "common.h"` head to closing brace). The later chunks of a concatenated file then lost their declarations. Symptom: `'D_80075B9C' undeclared` in the `gate.py --self-test` setup (`GATE CONTROL FAIL setup`, rock_04 plant). `make fleet` stayed green.

Move: every chunk that uses a hoisted symbol carries its own include of the header.
- Split each `src/**/*.c` at `#include "common.h"` lines (chunk 0 = file top).
- Symbol set = all decls of the hoisted headers.
- A chunk needs header H when it uses a symbol that it neither declares at depth 0 nor `#define`s. A use is at brace depth > 0, not after `.`/`->`, with comments and strings stripped.
- Skip H when an include of the chunk reaches H transitively.
- Insert after the chunk's last include before the first use (C0330). Additions only. The fleet stayed byte-identical (T10.c4: 615 includes, 115 files).

Check: `gate.py --self-test` = `GATE CONTROL OK` (fresh volume: census first, C0314).
Weak spot: a file-scope initializer use counts as a declaration in that scan.
