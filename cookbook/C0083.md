# C0083 — Cross-jump: a fall-through arm ending in a call never merges; a store tail merges the call
tags: idiom,sym-cross-jump,G-jump,jump2,cross-jump,call · date: 2026-10-02 · phase/task: 1.7/T5 · origin: mmx6 repro

1. **Residual (tell)**: an if/else calls the same function in both arms with two `jal`, where the target has one shared `jal` with only the argument set per arm (or the reverse). `sym-cross-jump`
2. **Mechanism**: jump2 (G-jump) cross-jumping walks back from the arm's jump and from its label while insn codes match. flow ends a block that ends in a call with `(use (const_int 0))`, so a fall-through arm ending in a call never matches: the call veto.
   - src:gcc-2.95.2/gcc/jump.c:1974 "find_cross_jump (insn, JUMP_LABEL (insn), 1,"
   - src:gcc-2.95.2/gcc/jump.c:2871 "GET_CODE (i1) != GET_CODE (i2))"
   - src:gcc-2.95.2/gcc/flow.c:605 "rtx nop = gen_rtx_USE (VOIDmode, const0_rtx);"
   - a-side `.jump2`: `(use (const_int 0 [0x0]))` before the join label.
3. **Lever**: where the shared tail is written. `if (a) g(1); else g(2); G = 3;` -> two `jal`; `if (a) { g(1); G = 3; } else { g(2); G = 3; }` -> the store and the call merge, one `jal`. A call-only shared tail (`g(3)` in both arms) is never merged (observed, scratch).
