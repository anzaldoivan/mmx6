# .DELETE_ON_ERROR for rules ending in a hash check

Without `.DELETE_ON_ERROR:` a make rule whose last step is a hash check (`sha1sum -c`) leaves the bad output on disk; the next `make` sees it up to date and exits 0. Put `.DELETE_ON_ERROR:` in the Makefile.
