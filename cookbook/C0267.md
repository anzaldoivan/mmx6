# Check a third-party address list against our census before using it as a lead

Use: any community address list (mod symbols, Tweaks workbook, Archipelago client, RAM watch) before a name joins the queue.


- Control first. One address known true (BinSeek 0x80016858) must be an exact start in `.run/oracle/functions.tsv`. Abort if not.
- Code at an exact start is consistent-with-bytes.
- Code inside a function is a mismatch. Write `inside func_X+0xNN` in the check, because most community "func" rows are hook or patch sites.
- An address in data or padding is a mismatch. An address that no image covers is not-checkable.
- Overlays: take the nearest load base at or below the address in `config/loadmap.txt`. 0x801EA000 is members 0-1, 0x800FA000 is members 33-58, and 0x800E9860 is members 2-32.
- Test every member of that group and name the members that hold the start.
- Data inside a data, rodata or bss split, or at a `config/symbols*` symbol, is consistent.
- Data inside a text split is a mismatch. Overlay splits are coarse, so overlay tables land in `c` splits. That is a split artefact, not a source error.
- Scratchpad and heap addresses are not-checkable.
- The status text names the function or split, so 2.3 can reuse it. Roles are in our words, never the source's identifiers (G102).
