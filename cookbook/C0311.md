# Ledger files keep their lines: cite tools skip them

- Context: commit_task's gate (psxd_floor protected check) refuses any lost or changed line in a ledger. A ledger is a file named by the [own], [trial], [floor] or [debt] tables of config/psxdecomp.toml, for example docs/ops/campaign.md.
- Trap: a repoint or a hand fix of an old path in a ledger line makes the commit fail with `GATE FAIL protected: <file> lost or changed 1 line(s)`.
- Move: a cite checker or rewriter reads that table set with tomllib and leaves those files out. A ledger cite is a record of its time.
- Where: tools/mmx6/layout.py `ledgers()`, used by `cite_files()`.
- Source: 2.4 T17.c2.
