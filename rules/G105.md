# G105 — Types live in one evidence-backed header, keyed by shape and fleet-gated
id: G105 · group: G · status: active · tags: decomp,types,gate · origin: mmx6 1.6/T3 · added: 2026-10-01

Every typedef and struct lives in `include/mmx6/types.h`, each with a `// evidence:` line; probe sources included.
`tools/mmx6/typecheck.py` keys each definition by shape (scalar: width, signedness; struct: size and ordered
(offset, width)) and refuses a duplicate shape under a new name, a definition outside `include/mmx6/`, a raw address
cast in `src/<prog>/`, and any definition it cannot key. Rung th-types makes this a fleet failure. Before the first
bank that needs a new kind of type, extend the keyer first (skill typecheck-fnptr-keyer-first).
provenance: mmx6 1.6 T3 (types.h, typecheck.py, TYPES CONTROL OK); G62
