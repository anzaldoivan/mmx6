# C0465 — A pin on an unread call argument: call through a cast with fewer arguments
tags: lever,pin,call,cast,argument,a2,constant · date: 2026-11-14 · phase/task: 3.2/T3 · origin: mmx6 T3.c6 set_shot_types

## Problem
A pin holds a constant in an argument register across a call (3.2 T3.c6, set_shot_types 0x8003DF58 `k` $6). Unpinned, the call reloads `li a2,2`.

## Move
- Check whether the callee reads that parameter. If it never does, call it through a cast with fewer arguments: `((void (*)(void*, s32))func_8003F7BC)(self, 1)`.
- Write the constant literally in the compares. The argument register keeps the compare's value, as in the target.
- Behaviour is unchanged only because the callee ignores the parameter: state that in the review.
