# C0466 — Address recomputed per store: split a || b test into if/else-if with the store twice
tags: lever,short-circuit,else-if,duplicate-store,cross-jump,regalloc,address · date: 2026-11-14 · phase/task: 3.2/T4 · origin: 3.2 T4.c13 func_800319EC

When: a draft writes `if (a || b) store;` and the compiler computes the address once for that one store. The target
instead computes the table or field address again before the second store, so a short register or order miss is left.

Move: write `if (a) store; else if (b) store;`, the store twice. cc1 merges the two
stores (cross-jump) but keeps the address computed again per arm, like the target.

Evidence: 3.2 T4.c13, SLUS func_800319EC (239 words, a jump-table switch). The last miss before 239/239 on probe 7 was
the flag3 test, and `if (mode == 0) S; else if (flag3 == 0) S;` matched. Related: C0336 (a goto folds into one ||
condition, the other direction) and C0366 (copied tails merge back).
