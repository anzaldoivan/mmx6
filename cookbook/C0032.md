# binutils mipsel as inserts sync before ll

binutils 2.42 mipsel `as` inserts `sync` before every `ll` unless `-mno-fix-loongson3-llsc` is passed; data disassembled as code then grows and the hash breaks. Add the flag to ASFLAGS.
