# C0259 — In-body #ifdef sends a port to preprocessed text: resolve conditionals, keep macros
tags: x4,port,macro,ifdef,repin,raw-body,debt · date: 2026-10-25 · phase/task: 2.1/T6 · origin: 2.1 T6.c1

- Symptom: an x4 port reads macro-expanded. `FIXED(8)` shows as `((s32)((8) * 0x10000))`.
- `SP_CUR_MAIN_OBJ` shows as a raw `0x1F800000 + 0x04C` cast, and the debt floor counts the offsets.
- Cause: upstream wraps a statement in `#ifdef MMX4_SATURN` or `#ifdef MMX4_PC`.
- x4port `raw_body` refused any raw definition with a `#` line. It fell back to the cpp item text.
- Fix (2.1/T6.c1): `resolve_ifdefs(raw, defined)` evaluates `#ifdef`, `#ifndef`, `#if [!]defined X`, `#else`, `#endif`.
- It checks names against `TU.defined`, the full `-dM` set. It drops directives and dead branches.
- Any other directive keeps the pp fallback. The port note reads `(raw-if)`.
- Re-port a file already at the pin: `--repin` never rewrites at-pin files.
- So set its header `@<pin>` to `@0000000` for one run. Only those files rewrite, with casts and `// !` marks kept.
- Then run `make format` and pull.
- Side effect: removed offsets lower the debt `offset` count. `debt` fails `stale offset` until `debt --update` records the drop.
- Repin prints `at pin, port differs` for kept bodies with T5 call casts (C0258). That is expected.
- A new such line after a port() change marks a body the change now ports differently. Inspect it.
