# C0092 — Target-specific make vars are invisible to other targets: splice make -n -B's recipe line
tags: make,toolchain,flags,dumps · date: 2026-10-02 · phase/task: 1.7/T2 · origin: mmx6 T2

Per-unit flags set as `target: CFLAGS += …` exist only for that target. A tool that must compile "as the rule does" (dumps, permuter, probes) takes the recipe from `make -s -n -B build/<c>.o` and runs its stages, instead of re-expanding variables in a new target that forks the flags.
