# C0113 — Linear compare chain in retail is an if/else-if chain, not a switch
tags: lever,switch,if-chain,dispatch,case-tree,block-order · date: 2026-10-03 · phase/task: 1.8/T13 · origin: mmx6 W4

1. **Residual (tell)**: Retail compares a small, irregular case set one value after another. This is a linear chain of equality branches in source order. The draft's `switch` emits a balanced compare tree (or a range node). As a result, block order and the score collapse.
2. **Mechanism**: This is observed, not source-proven. The compiler gcc 2.95 lowers a sparse switch through its case-node tree, never a linear chain. That tree is balanced, with consecutive same-label cases merged into one range. An if/else-if chain keeps the written order.
3. **Lever**: Write the dispatch as `if (x == A) … else if (x == B) …` (or `||` for shared bodies) in retail's compare order. Do likewise for a masked dispatch (`x & 0xF0`). If an inner switch's tree pivots differently from retail, give consecutive same-body cases separate bodies. Then the compiler does not merge them into one range node.
4. **Byte proof**: In wave W4 (1.8/T13), rock_08:0x800F0200 went 51 → 271/271 and rock_10:0x800F44A0 is at 261/261 (both banked).
