# C0040 — make -j extract build races. Run extract as its own make call first
tags: make,parallel,extract,race · date: 2026-10-01 · phase/task: 1.4/T4 · origin: mmx6 T4

With `make -j extract build`, make can evaluate the build's prerequisites before extract writes them. Run `make extract` first. Then run the build targets.
