# dumpsxiso writes an XML project file into its cwd

Besides `license_data.dat` in the `-x` directory (C0008), dumpsxiso writes an XML project file into the current
working directory. For example, it writes `/work/ref.xml` when you run it from the tree root. Run it from a scratch
dir, or move the XML out before a diff, `git status` checks or a tree sync.
