# C0002 — The triage table: diff tell to mechanism to lever family
tags: triage,symptom,tell,spill,register-pressure,aliasing,callee-saved,branch-polarity,cross-jump · date: 2026-10-01 · phase/task: - · origin: decomp-architect

The index a worker greps before recurring matching work: find the tell, read the mechanism, try the lever family, then
open the cookbook entries the last column names.

| Tell in the diff | Likely mechanism | Lever family | Entries |
|---|---|---|---|
| a temporary in a spill slot `sym-spill-slot` | a reload artifact | reshape the live range; declaration order | C0085 |
| every small edit moves 20+ instructions `sym-register-pressure` | a register-pressure lock | hand to the permuter | → permuter |
| a load stuck below a store while other loads float `sym-load-below-store` | an aliasing decision | the source's aliasing facts | C0081 |
| a phantom callee-saved register `sym-phantom-callee-saved` | cross-call value caching / the allocation order | count the uses; re-shape | C0076 |
| a shift off by ×4 against the target `sym-shift-x4` | the scaffold's pointer arithmetic | cast through a byte pointer | C0084 |
| a branch's arms swapped `sym-branch-arms-swapped` | branch polarity | put the fall-through block in the `if` | C0082 |
| a cross-jumped tail merged or not merged `sym-cross-jump` | the cross-jump count law | shape the shared block count | C0083 |
| a global reloaded after a pointer store, or not reloaded `sym-global-reload` | cse store invalidation (/s aliasing) | the store's form: `*p=` vs `p[k]=`/`p->f=` | C0075, C0086 |
| a counted loop ending `bgez` vs `bgtz`/`bne` `sym-loop-reversed` | loop reversal (check_dbra_loop) | write the count direction | C0077, C0087 |
| `lw` + `andi 0xff` vs one `lbu` `sym-narrow-load` | combine extraction, blocked by a second use | the word's other uses | C0078, C0088, C0089 |
| two values' `$16`/`$17` swapped `sym-sreg-swapped` | global-alloc priority (density, then pseudo order) | move references; declaration order | C0079, C0080 |

*Grow this table as the cookbook grows: the Entries column names the entries that prove each row
(`→ permuter` for an intrinsic tell), and a new tell gets a row the day its first entry lands.*
