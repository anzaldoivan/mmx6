## Design
- X, Y = two lowest-vram exe members of dup class of 0x8003744C (not exemplar) whose unit .c holds the exact 5-line define block (`block(esrc, …, [(func_8003744C, X), (D_80073C1C, tbl)])`); X table = block's D_80073C1C value. Run: X=func_80041BE8, Y=func_80041F30 (32208.c).
- Plant via `put()` (bottom-up per unit): block -> `INCLUDE_ASM("asm/<prog>/nonmatchings/<tu>", <func>);`; asm/…/<func>.s = neighbour header (`.set noat/noreorder`, `nonmatching f, 0xN`, glabel, endlabel) + one `/* <romoff> <vram> <LE bytes> */  .word 0x…` per word.
- Words: `probe.retail_words` (trimmed after jr $ra, C0021) + untrimmed tail up to corpus `end` read via `probe.yaml_layout` (deviation: padding words must be present or the link shifts).
- Plant gate: `rebuild(prog)` rc 0 AND exe sha1 == pre-test sha1, else FAIL.
- Corpus: `corpus.py --all` (`--prog` would rewrite functions/spans/denominators.jsonl with one program only); all three build/corpus/*.jsonl saved as bytes first and restored in teardown. Then X, Y must read include_asm.
- Controls A/B unchanged; per-control snapshot = planted state, restored + rebuilt after each.
- Teardown (finally): restore(saved) (src units, planted .s deleted as previously absent), rm src/shared/_selftest + build copy, corpus bytes restored, rebuild prog.
- Fail-closed end: sha1 map of every file under src/ == pre-test, registry sha1, exe sha1 == pre-test.
