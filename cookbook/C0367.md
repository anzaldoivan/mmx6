# depin/probe misjudge pins in #included member files and multi-function files: verify by the build hash

- Seen: T10.c2 (2.6).
- A function whose body lives in a file #included by a wrapper TU (e.g. 3CE30.c): probe.py find_extent ends the retail span at the next symbol known from that .c only, so it scores ~26/150 and depin says `refused`.
- depin on one function of a multi-function file trial-drops pins in other functions and "matches" them (the probe scores only its own function). Pass only the function holding the pin.
- Fallback: per trial, push the file into /work, incremental `make build`, compare the SLUS sha1. Run a negative control (a deliberate wrong drop must FAIL) so the verifier is proven to read the file.
