# Loop end bound spelled as the pool base plus its size, not a separate end symbol

Symptom: a forward scan over a fixed-stride pool matches except the bound. Retail derives the end address from the pool base, one high part shared with the start. A separate end extern or absolute address gets its own relocation pair.

Lever: spell the bound from the base, `for (p = POOL; p < POOL + 0x1400; p += 0xA0)`, so the end shares the base symbol. A banked twin over the same pool (here the two-direction func_8002BEC4) seeds the rest of the body.

Seen: W26 SLUS_013.95 2C32C (T26 c51, 81/81).
