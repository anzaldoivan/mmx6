# C0038 — An INCLUDE_ASM probe control is triple-independent. Pair it with a planted one-word mutation
tags: probe,control,compare,masking · date: 2026-10-01 · phase/task: 1.4/T3 · origin: mmx6 T3

A known-true control built from INCLUDE_ASM of the target's own asm matches under every triple. It validates extraction offsets, extents and relocation masking, not the compiler. Pair it with a runtime-generated one-word mutation that must FAIL. The mutation then catches a comparator that always says MATCH. Generate the mutation in scratch, and never track it (firewall).

Source: phase 1.4 T3 (probe.py --self-test: MATCH 32/32 and FAIL 31/32 per triple).
