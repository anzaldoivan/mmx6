# C0447 — gate.py -j 3 restore-rebuild stops and worker FileNotFoundError: re-gate -j 1 from a sub-root
tags: gate,bank,wave,parallel · date: 2026-11-11 · phase/task: 3.1/T15 · origin: T15.c1

Symptom: `gate.py --wave` at the default `-j 3` stops many rows with `(restore rebuild rc 2)` in the bank note. Some
program workers also die with `GATE WORKER <prog> error FileNotFoundError: .run/bank/<prog>.<func>.log`. This happens
when a ladder step's probe fails before bank.py writes its log. These rows are not walls.

Move: re-gate the same wave with `-j 1`. For a program whose worker died, copy only its open packs to a sub-root,
`<root>/rest/W<n>/<prog>_<func>/`. Then gate that root, so banked rows are not gated again. Keep the sub-root, because
the journal records point at its drafts.

Evidence: 3.1 T15.c1 gated W302, 21 pilot drafts. The `-j 3` run took 416 s and gave 13 restore-rebuild stops. The
journal holds 14 such stops ever. The `-j 1` run took 782 s and banked 10 of them. Three sub-root re-gates banked the
rest that could bank. Logs: .run/3.1/logs/t15c1-gate*.
