# Static inline helper for a tail of constant stores plus a call: early argument setup

Symptom: a schedule residual. Retail sets up the argument registers of the final call early, ahead of a run of constant field stores. Statement-order sweeps and pins do not move them.

Lever: move the constant-store run and the final call into a `static inline` helper (unique name, C0187) taking `self` and the call's second argument. The inline parameter copies become early pseudos, so the argument setup is scheduled before the stores. Then sweep the store order inside the helper.
