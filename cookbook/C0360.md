# carve.py refuses a mid-file cut in a role file: bank in place
- `carve.py opt <prog> <unit> <vram>` cuts only where a TU may start.
  A function in the middle of a role file (several functions, e.g. 8003F3DC.c) gives `CARVE REFUSE role-split func_X is inside role file ...`.
- In a thin unit, cut only at role-file starts: check config/layout.tsv first/last of the target file and the next.
- Refused: bank in place in the shared unit (the gate decides). C0288 applies only when the target starts a file.
- A second carve inside a freshly carved TU needs the C0289 re-split first (`not-a-start ... inside TU`).
