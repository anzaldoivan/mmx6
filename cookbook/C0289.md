# Re-split after a plant or carve: delete asm/<prog> and the split stamp

- A `.c` edit alone does not make `build/split/<prog>.stamp` stale.
- Splat never deletes the old `.s` of a moved function.
- After you plant INCLUDE_ASM or carve a unit, run `rm -rf asm/<prog> build/split/<prog>.stamp` before the rebuild.
  Otherwise the build uses stale asm (a missing tail-unit .s, a red hash).
- `corpus.py --prog P` rewrites functions.jsonl with the rows of P only. A later `sig.py --rescan` then refuses
  `stale census`. Run `corpus.py --all` instead (about 1 s).
