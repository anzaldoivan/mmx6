# A jtbl-uncarved verdict can be stale: check the table's words against the function's span
- `config/boundaries.txt` can assign a jump table to the wrong function. T26.c3 found 3: lo 0x8001004C (row says func_80015230, words point into 0x800158F0), 0x80011694, 0x80010F38 (func_8004FFF8's table is func_80050670's).
- Before carving for a `jtbl-uncarved` ledger verdict, read the table words. If none falls in the function's span, the function has no table. Draft it as a plain body and bank it in place.
- A function whose table cannot be carved yet still decompiles with a hand-made rodata `.s` of the retail words. Keep it scratch, never tracked (G12).
