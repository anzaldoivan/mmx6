# Rename a twin member's callees and globals by aligning the exemplar object's relocations with retail
- Symptom: a dup member probe-matches with relocations masked, but R5 is red (refusecause `reloc`).
- The linked word names the exemplar's callee or global, and retail names the member's (an R26 or HI16/LO16 mismatch).
- Fix: walk the exemplar's built object relocations (R26, HI16+LO16 pairs). Per word, the shift is the member retail target less the exemplar retail target.
- Map symbol S to the member's name at addr(S) plus the shift, with the addend kept. So `D_X+0xA` maps through its base D_X.
- Add `#define S T` to the member's include block only when S is in the body and the shift is nonzero.
- Skip S when the unit aliases it already (C0225), or when its words disagree on the shift.
- Name source: the exact-address symbol in build/<prog>.map. A real name can carry a header prototype the body's call does not fit (R2 `too few arguments`). Pair it with prototype repair.
- Only the clean-rebuild hash decides (C0062). Result: 29 of 72 reloc rows gated with R5 green, reloc 72 -> 1 (3.1 T5, propagate.py relocdef).
