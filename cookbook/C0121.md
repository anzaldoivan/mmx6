# C0121 — A loop gcc reverses: up-count source puts the base register first, down-count the counter first
tags: lever,loop,loop-reversal,register-order,regalloc · date: 2026-10-04 · phase/task: 1.8/T13 · origin: mmx6 W4

1. **Residual (tell)**: a reversed (count-down) loop whose base pointer and counter registers are swapped against retail.
2. **Mechanism**: observed. When loop.c reverses an up-counting source loop, the base register is allocated before the counter; a source loop written down-counting allocates the counter first.
3. **Lever**: pick the source loop direction by the register order retail shows, not only by the branch (extends C0077).
4. **Byte proof**: wave W4 (1.8/T13 c15), banked.
