# C0121 — A loop gcc reverses: up-count source puts the base register first, down-count the counter first
tags: lever,loop,loop-reversal,register-order,regalloc · date: 2026-10-04 · phase/task: 1.8/T13 · origin: mmx6 W4

1. **Residual (tell)**: A reversed (count-down) loop has its base pointer and counter registers swapped against retail.
2. **Mechanism**: This is observed. When loop.c reverses an up-counting source loop, the compiler allocates the base register before the counter. A source loop written down-counting allocates the counter first.
3. **Lever**: Pick the source loop direction by the register order that retail shows, not only by the branch. This lever extends C0077.
4. **Byte proof**: The proof is in wave W4 (1.8/T13 c15), banked.
