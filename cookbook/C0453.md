# C0453 — harvest.py --start on a drawless bank wave needs report.py --all and a default draw first
tags: harvest,bank-wave,draw,report,stamp · date: 2026-11-12 · phase/task: 3.1/T18 · origin: mmx6 T18.c1 W305

Symptom: `harvest.py --start W<n>` fails on a bank wave that skipped the draw (a sample or after-run wave).
Cause: --start reads the census report and the default draw output for its denominators.
Fix: first run `mx.sh run python3 tools/mmx6/report.py --all` and a default `draw.py` run first, then `--start W<n>`, `--inert-wave W<n>`, `--widen W<n>`, `--gate W<n>`. With 0 live levers no --record or --sweep is needed. Then the final fleet: before the stamp th-harvest is red `HARVEST GATE W<n> MISSING stamp` though FLEET 57 of 57 prints. Seen 3.1 T18.c1 (W305).
