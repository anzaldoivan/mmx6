# Unbank a body in an L-B self-test: cut its role-file chunk, never delete the file

Under L-B a body lives as one chunk of a multi-function role file (`src/<prog>/<vram>.c`), included by a thin unit.
The chunk begins at its own `#include "common.h"` line (the old self-contained body file's head) and ends at the
definition's closing brace (`layout.locate(prog, func)` gives the lines).

- Undo (unbank): replace that span with the `INCLUDE_ASM(...)` line (plus any `extern` the asm needs).
- Draft: the cut span compiles standalone. Included back, it is the same TU text.
- Derive the unit (tu) from the corpus row or `layout.locate(...)[3]`, never from the file basename: a role file's
  stem (`801EBEEC.c`) is not its unit (`1EA000`).
- A planted role tree adds an include level above the block's existing role file. Check that the block is unchanged and
  its file is in `declsync.unit_files(prog, [role])`.

Source: tools/mmx6/gate.py `body_span`, bank.py role pass (T21.1.c1, commit 5bda739c2).
