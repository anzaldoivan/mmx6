# A switch default arm that repeats the fall-through store becomes `break`

Problem: a `default:` arm does `v = k; goto store;`, where `store` is the store after the switch.

Move: when the default stores the fall-through value, write `break;`. gcc 2.95 emits the
same join, the goto is gone and the bytes are identical.

Related: an if/else inside each case can halve a C0176 family of gotos into a shared switch tail. Merging the
identical cases instead moved bytes (rock_14 E9A34).

Evidence: 2.5/T11.c9, rock_07 E9C98 (two default arms), rock_14 E9A34 (four retile gotos removed).
