# C0115 — A goto to the body in one arm stops jump2 cross-jumping identical compare tails
tags: lever,goto,cross-jump,jump2,arm-order,block-order · date: 2026-10-03 · phase/task: 1.8/T13 · origin: mmx6 W4

1. **Residual (tell)**: two arms that each end in the same threshold compare and branch to the same return are merged into one tail in the draft (one compare, jumps into it), while retail keeps a separate compare per arm, the first as a branch to the body followed by a jump to the return.
2. **Mechanism**: observed. jump2 cross-jumping merges identical instruction tails that flow to one label; an explicit `goto` to the body plus a bare `return` in the first arm changes the tail so the two no longer match.
3. **Lever**: in the first arm write `if (d >= K) goto body; return;` instead of the shared condition; also order if/else arms as retail places the blocks (the non-zero-counter arm first here).
