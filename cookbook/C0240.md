# PsyQ LIB → OBJ → ELF on an arm64 Mac, and the masked check against retail

- Split a PsyQ `.LIB` (magic `LIB\x01`, not `ar`): psy-k has no release binaries. Build it in a minute:
  `docker run --rm -v <out>:/out rust:slim cargo install psy-k --version =0.4.0 --locked --root /out/psyk`
  (native arm64 is fine). Run `psyk extract <LIB>` with cwd = output dir (one OBJ per member). `psylib -h` prints nothing. Use `psyk`.
- Convert: psyq-obj-parser (psyz release `requirements`, static linux x86-64) needs `--platform linux/amd64`:
  `psyq-obj-parser <X>.OBJ -n -o <X>.elf` (verbose trace, rc 0).
- Compare: ELF .text vs exe bytes at `vaddr - t_addr + 0x800` (assert `PS-X EXE`), masking every word a .rel/.rela entry targets.
  Control: shift the span by 4 bytes and the differ count must explode.
- Keep vendor bytes in `.run/<phase>/` via a bind mount of that dir (plain `docker run`), not the mx.sh work volume.
