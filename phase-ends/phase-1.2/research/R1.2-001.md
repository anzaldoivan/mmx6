## Answer
1. Loader name "PSX Executables Loader". PsyQ version is auto-detected at import (DetectPsyQ), stored as program property "PsyQ Version" in Program Information (also a loader option). Analyzer "PsyQ Signatures" (default on, applies JSON sigs from psyq/<ver>/); no UI deps seen, so headless should work (inferred). Overlays: GUI-only Swing panel (OverlayManager); no headless raw/overlay option found, so script it yourself (Ghidra script: createMemoryBlock + setBytes).
2. GhidrAssistMCP supports headless via analyzeHeadless + GAMCPStartServerScript.java pre-script (wait=true keeps it alive). SSE (/sse, /message) and Streamable HTTP (/mcp). Default localhost:8080. Health check: curl http://localhost:8080/sse (streams; use --max-time).
3. PCSX-Redux flags: -run -iso -bios -exe/-loadexe -dofile -exec -stdout -lua_stdout -no-ui -cli -testmode -webserver -webserver-port -interpreter -safe -portable. Lua: PCSX.getMemPtr (8MB uint8_t*), addBreakpoint(addr,'Exec',...), createSaveState/loadSaveState, Support.File.open(f,'TRUNCATE'):write/close, PCSX.quit([code]). Web server default port 8080 (conflicts with GhidrAssistMCP default 8080! set one differently).

## Findings
- psx_ldr: no analyzer-reported bookmark; version not obviously in import log. Marker files PSYQ_XXX / PSYQ_LIBNAME_XXX are for the PsyqLoader (lib/obj import), not the exe.
- Loader options: RAM base (default 0x80000000), RAM size (0x200000), PsyQ Version. README snippet claimed -ramStart/-ramSize command-line prefixes (unverified; use `-loader PSX Executables Loader -loader-ramStart ...` form only after testing). Likely: analyzeHeadless <proj> <name> -import SLUS_013.95 -loader "PSX Executables Loader" (exact flag spelling untested; unspecified loader also lets auto-detect work). Loader sets "Non-Returning Functions - Discovered" off.
- Ghidra 12.1.3 compatibility of ghidra_psx_ldr not confirmed from docs (user has it installed; check extension version).
- Headless GhidrAssistMCP: details from README summary; exact -preScript argument syntax not verified.
- PCSX-Redux: "-testmode" makes pcsx_exit() exit the emulator. Flags are dash-insensitive. -cli = -no-ui + -safe. bios/iso/exe/archive must exist else exit 1. -loadexe must be last on some wrappers.
- Lua runs on main thread; PCSX.quit is deferred until current Lua chunk ends. Savestate from createSaveState is uncompressed protobuf (UI states are gzip).
- Web: enable with -webserver / config; GET /api/v1/cpu/ram/raw, /api/v1/gpu/vram/raw, /api/v1/execution-flow, /api/v1/screen/still; POST /api/v1/execution-flow?function=pause|start|resume|reset&type=hard|soft; /api/v1/state/{op}; /api/v1/lua/{handler}. Quick RAM dump: curl -o ram.bin localhost:8080/api/v1/cpu/ram/raw.
- Suggested unattended pattern: pcsx-redux -no-ui -testmode -stdout -lua_stdout -bios X -iso game.cue -run -dofile oracle.lua; oracle.lua adds Exec breakpoint, dumps RAM via Support.File, calls PCSX.quit(0).
