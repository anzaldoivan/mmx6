# C0137 — Signed-byte spellings: s32 temp + (s8) test, s8 view decrement, (s8) of u8 element, s8 switch, u16 via ori
tags: lever,s8,u8,sign-extension,byte,decrement,switch · date: 2026-10-04 · phase/task: 1.8.1/T5 · origin: mmx6 W5

These signed-byte spellings select retail's exact insns (gcc 2.95, PSX):
- A byte decrement tested by sign (`sll 24; bgez`) is an s32 temp stored back and an `(s8)` cast on the test. An s8 local sign-extends with sra, and a u8 local masks with andi (c16).
- `s8field-- < 0` through an s8 field view gives lbu+sll24 and `-1` (the retail form here). `(s8)u8field-- < 0` gives `addiu +255` (c27).
- `lbu` + `sll 24` + `sra 24` is an `(s8)` cast of a u8 element, not an s8 declaration (c32).
- An `lb` that feeds a switch is `switch (*(s8 *)(p + off))` (c25).
- `ori 0xFFxx` before a halfword store means that the field is u16, not s16 (c2).
