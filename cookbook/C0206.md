# Read globals and fields into s32 block locals before the call or store that fixes load order

- Symptom: retail reads its inputs early. Examples are player x and y, tile shifts, a scratch base and offset, a global compared later, and a table half.
- m2c leaves the expressions inline at their use. The loads then land late or in the wrong registers.
- Lever: declare one s32 local in the block per value, in retail's read order.
- Fill each local before the first call, or before the store it must precede.
- Use the locals in the later compare, difference or store. Never re-read the global.
- Start without numeric pins. SLUS 47E34 matched only after the pins were dropped and the table byte was read by direct array index.
- Seen W27: SLUS 41290, 2FE30, 47E34, rock_24 EF820. Related: C0148 (two globals), C0159 (single store).
