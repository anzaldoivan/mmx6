# Overlay-local symbol refused on a member: alias it around the include
- A propagated member can be refused by the propagate R5 check while the exemplar body is unchanged.
- Cause: the exemplar body uses an overlay-local symbol (a data symbol or a callee).
- Fix: alias the exemplar's symbol name to the member overlay's name around the include, on the member TU only.
- Propagate may add one alias itself. Check for a duplicate before you add one by hand.
- A second C name for an existing address (a flat view of a 2-D array) is a plain extern with a suffixed name. The link provides it. The verbatim check refuses an alias via the label extension.
