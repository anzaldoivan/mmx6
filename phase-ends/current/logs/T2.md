## Decision: pack location
- Container canonical: `/work/waves/W<n>/<prog>_<func>/` (card.md, ctx.h, scaffold.c, target.s, draft.c, verdict.json). mx.sh sync spares top-level `waves` as it spares `.run`.
- Mac mirror: `waves/` (gitignored, so sync never ships or clobbers it); everything but `*.s`. Transport: new `mx.sh push <waves/…>` (Mac → /work, no wipe), `mx.sh pull waves/…` excludes `*.s`.
- Compile isolation: a pack compile runs in a snapshot `/work/waves/.iso/<tag>/` (read-only big trees hardlinked, writable inputs copied), so a concurrent sync (which rm -rf's /work/asm, include, Makefile) cannot reach it. Rejected: `/work/.run/waves` (Mac .run never syncs, same transport need, and scratch.py caps .run); second named volume (probe compiles cwd-relative under /work; would need copying anyway).
- Proven by host control script (sync during a held compile; negative control without snapshot).
