# A pinned copy of a parameter: assign the parameter 0 right after the pin (cse barrier)

Symptom: `register T x asm("$17") = arg0;` costs an extra callee-saved register and a copy, because cse replaces some uses of `x` with the parameter pseudo.

Lever: write `arg0 = 0;` right after the pin. Then cse can no longer substitute the parameter. Later, the compiler deletes the dead store and the extra register disappears.

Evidence: W12 rock_18 EAAC0 (c27: part of an 18-row residual). The function closed on retry c65 with C0136 + C0137.
Related: C0141 (numeric pins).
