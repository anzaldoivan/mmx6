# binutils mipsel as inserts sync before ll

Unless you pass `-mno-fix-loongson3-llsc`, binutils 2.42 mipsel `as` inserts `sync` before every `ll`. Data disassembled as code then grows, and the hash breaks. Add the flag to ASFLAGS.
