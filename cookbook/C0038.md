# C0038 — An INCLUDE_ASM probe control is triple-independent; pair it with a planted one-word mutation
tags: probe,control,compare,masking · date: 2026-10-01 · phase/task: 1.4/T3 · origin: mmx6 T3

A known-true control built from INCLUDE_ASM of the target's own asm matches under every triple: it validates extraction offsets, extents and relocation masking, not the compiler. Pair it with a runtime-generated one-word mutation that must FAIL, so a comparator that always says MATCH is caught. Generate the mutation in scratch, never tracked (firewall).
