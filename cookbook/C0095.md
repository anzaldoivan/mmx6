# C0095 — Allocation-order reproducers must keep values live across a block boundary
tags: gcc,greg,regalloc,reproducer · date: 2026-10-02 · phase/task: 1.7/T3 · origin: mmx6 T3

In gcc 2.95.2 block-local pseudos are placed by local-alloc (`.lreg`) and never appear in `.greg`'s `;; N regs to allocate:` order line. A reproducer aimed at global allocation order keeps its values live across a call plus a branch.
