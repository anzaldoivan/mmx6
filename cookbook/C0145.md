# Store a computed byte to its field, then re-read the field at each later use instead of a local

Symptom: retail masks or reloads a byte value after storing it (a fresh load from the field at each use).
A draft that holds the value in a local keeps it in a register and drops the reload or the mask.

Lever: store the value to its field once. Then write every later use as a read of that field, not of the
local. Examples of a later use are an index and a call argument plus an offset. Retail compiled the
store/load through the object, and cse cannot forward the stored value across the intervening call or
aliasing store.

Case: W7 rock_22:0x800EF5B8 (T7). The case stores a table byte to field 0x88. The 0x54 pointer index and
the call argument re-read it. Related: C0107 (stores that force a reload), C0139 (aliasing decides moves).
