# C0291 — Token check a regroup: Makefile cpp output, linemarker and blank lines dropped, equal
tags: cpp,layout,regroup,token-check,host · date: 2026-10-31 · phase/task: 2.4/T4 · origin: mmx6 T4.c1

This check proves a regroup of a unit's #includes byte-neutral, before any build. Preprocess the old and the new unit
with the Makefile's own `$(CPP) $(CPPFLAGS)` (+ `-DMMX6_OVERLAY` for rock_*). Drop `#` linemarker lines and blank
lines, and compare. Identical text means cc1 sees the same tokens (no `__LINE__`/`__FILE__` in src/). `tools/mmx6/layout.py
apply` runs it per unit before writing anything (2.4 T4).

Trap: the macOS host `/usr/bin/cpp` is clang in traditional mode. It keeps `//` comments and does not stringize `#`,
so it cannot judge tokens. Use the container's mipsel-linux-gnu-cpp. A host fallback for a planted self-test is
`cc -E -x c`, never `/usr/bin/cpp`.
