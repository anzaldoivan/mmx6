# Parallelize a serial make check chain: per-rung stamps, a marker goal, and let -j find the undeclared deps

- Move (3.0 T6): run the rungs as one sub-make `-j$(JOBS) -Otarget th-par`. The order of the exclusive rungs applies only when the phony marker goal `th-par` is in MAKECMDGOALS.
- Why a goal: a command-line variable rides MAKEFLAGS into every tool's nested make. A goal does not.
- Timing: under -j, a "since the previous rung" mark is racy and means nothing. Each rung recipe starts with `@$(th_t0)` and ends with `@$(th_t1)`, with a stamp per rung under build/th-wall.
- TH-WALL is then the rung's own start-to-end time. Neighbours inflate it, so the rung walls sum past the stage wall.
- Trap: the first parallel fleet exposed reads nobody declared. The harvest self-test copies census and draw files (FileNotFoundError). alloc_table re-dumps into build/dumps beside th-dumps (`ALLOC TRUNCATED`).
- Map each rung's reads and writes before -j. Then prove it with two clean runs that give identical summary lines.
- Exclusive rungs run after the parallel set, one at a time: in-place restore tools, shared worker trees, nested -j8.
- They bound the gain. In mmx6, health fell from 807 s to 700 s, because th-remap (160 s) cannot overlap th-harness.
