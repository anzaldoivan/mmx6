# C0048 — spimdisasm farthestBranch survives function ends. Declare sized func symbols
tags: splat,spimdisasm,overlay,boundaries · date: 2026-10-01 · phase/task: 1.5/T1 · origin: T1 overlay 0-glabel fix

spimdisasm never resets its farthestBranch at a function end. One data word that decodes as a far forward branch/jump disables `jr $ra` function ends for the rest of the section. The symptom is an overlay that splats to 0 glabels.

Fix: declare every start as a sized `type:func` symbol in config/symbols.<prog>.txt. Give each start a retail-byte basis (post-return, jal target, first code after header, data).
