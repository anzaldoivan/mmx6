# C0082 — beqz vs bnez: the if arm falls through. Invert the condition and swap the arms
tags: idiom,sym-branch-arms-swapped,G-jump,jump,polarity,branch · date: 2026-10-02 · phase/task: 1.7/T5 · origin: mmx6 repro

1. **Residual (tell)**: there is a `beqz` where the target has `bnez` (or the reverse). The code of the two arms appears in the other order. `sym-branch-arms-swapped`
2. **Mechanism**: expand sets the polarity, and jump (G-jump) keeps it. `if (c) A; else B;` jumps on !c to B, and A falls through. `!c` only swaps the labels. The jump pass swaps arms only for `if (foo) bar; else break;`.
   - src:gcc-2.95.2/gcc/stmt.c:1916 "do_jump (cond, thiscond->data.cond.next_label, NULL_RTX);"
   - src:gcc-2.95.2/gcc/expr.c:10667 "do_jump (TREE_OPERAND (exp, 0), if_true_label, if_false_label);"
   - a-side `.jump`: `(if_then_else (eq:SI (reg/v:SI 81)` (same in `.rtl`).
3. **Lever**: invert the source condition and swap the arms. The arm that must fall through goes in the `if`. Inertness checked: the non-branch lines are equal as a multiset, and the branch mnemonic differs.
