# C0122 — One variable per arm: a function-scope temp shared by two arms can swap callee-saved registers
tags: lever,regalloc,temp,callee-saved,arms,local · date: 2026-10-04 · phase/task: 1.8/T13 · origin: mmx6 W4

1. **Residual (tell)**: Two arms use `$s` registers with swapped numbers against retail.
2. **Mechanism**: This is observed. One function-scope temp used in both arms becomes one pseudo with a combined lifetime and priority. This reorders the callee-saved assignment. See C0106 for the opposite case.
3. **Lever**: Declare a separate block-scope variable in each arm.
4. **Byte proof**: The proof is in wave W4 (1.8/T13 c18), banked.
