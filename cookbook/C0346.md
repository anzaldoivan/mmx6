# C0346 — System membership: call-graph reach plus all-callers-inside fixpoint, host-side
tags: callgraph,membership,system,jal,dispatch-table,corpus,shared-helper · date: 2026-11-02 · phase/task: 2.6/T3 · origin: mmx6 2.6 T3.c1

- Need: a system's member set from the call graph (C0285), run on the host.
- Inputs: `build/corpus/functions.jsonl` lives in the container, and `mx.sh pull build/...` is firewall-refused (C0319). `cp` it to `.run/2.6/<T>/` in the container, then `mx.sh pull .run/...`. The retail image is already on the host: `extracted/retail/iso/SLUS_013.95`.
- Corpus `src` is only `c|asm`, no path. Map fn -> file by its C definition or `INCLUDE_ASM` line. Else take the SLUS file that `#include`s its `src/shared/` body or `#define`-aliases it.
- Dispatch tables: read words from the table symbol until the first word that is not a function start.
- Membership: reach down from entries (folder fns + table targets) over jal+table edges. Then run a fixpoint: a reached non-entry fn stays only if every caller is a member. Dropped = shared helpers (named only). File joins if > half its fns are members.
- Result 2.6 T3: 65 entries, 235 reached, 125 members, 50 files, 110 shared helpers. Most asm callees R2.6-005 called members were shared helpers. Script: `tools/mmx6/systems/callgraph.py` (was `.run/2.6/T3/cg.py`, see the README there).
