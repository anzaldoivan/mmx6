# C0481 — Goto loop to structured C: split the s8 step to block strength reduction, empty do-while to block rotation
tags: goto,goto-removal,loop,strength-reduction,giv,s8,rotation,do-while,for,break · date: 2026-11-15 · phase/task: 3.2/T6 · origin: mmx6 T6.c24 func_80033214

Symptom: a goto loop matches, but its structured form strength-reduces the s8 index or rotates the loop.
A goto loop with several entry points is skipped by loop.c, which is why the goto form escaped both.

Strength reduction: loop.c treats an s8 index as an induction variable when the shift-right directly follows the shift-left.
Write the step as `m = (i + 1) << 24; k++; i = m >> 24;`, with an unrelated statement between the shifts.
A plain `m = i + 1; i = m;` does not help, because the copy is folded before loop.c runs.

Rotation: an empty `do {} while (0);` at the top of the loop body stops the compiler from rotating it and peeling a step.

Layout: in a `for (;;)` with an early `break` path before an inner loop, the compiler moves the loop head to the bottom.
A path found before the loop can go in `if (t != 0) { found } else { for (;;) ... }`.
Put a copy of the found store inside the inner loop too, and the compiler merges the two copies.
