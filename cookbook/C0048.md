# C0048 — spimdisasm farthestBranch survives function ends; declare sized func symbols
tags: splat,spimdisasm,overlay,boundaries · date: 2026-10-01 · phase/task: 1.5/T1 · origin: T1 overlay 0-glabel fix

spimdisasm's farthestBranch is never reset at a function end: one data word decoding as a far forward branch/jump disables `jr $ra` function ends for the rest of the section (symptom: overlay splats to 0 glabels).

Fix: declare every start as a sized `type:func` symbol in config/symbols.<prog>.txt with a retail-byte basis (post-return, jal target, first code after header, data).
