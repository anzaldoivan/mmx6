# C0075 — Global reloaded after *p= but kept after p[k]=/p->f= (cse /s aliasing)
tags: idiom,sym-global-reload,G-expr,cse,aliasing,reload · date: 2026-10-01 · phase/task: 1.7/T4 · origin: mmx6 repro

1. **Residual (tell)**: a global reloaded (`lw` from `%lo(G)` a second time) after a store through a pointer, where the target keeps the first value (or the reverse). `sym-global-reload`
2. **Mechanism**: cse (G-expr). A store invalidates a table entry only on `true_dependence`; a fixed-address scalar (`mem/f` global) never aliases a varying-address `mem/s` store. Expand flags `p[k]`/`p->f` with /s, not a bare `*p`; QImode (u8) stores alias everything.

   - src:gcc-2.95.2/gcc/alias.c:1182 "if (MEM_SCALAR_P (mem1) && MEM_IN_STRUCT_P (mem2)"
   - src:gcc-2.95.2/gcc/expr.c:6267 "if (TREE_CODE (exp1) == PLUS_EXPR"
   - src:gcc-2.95.2/gcc/alias.c:1261 "if (mem_mode == QImode || GET_CODE (mem_addr) == AND)"
   - a-side `.cse`: `(set (mem:SI (reg/v:SI 81) 0)` (no /s), then a second `mem/f` load of G.
3. **Lever**: write the store as `p[k] =` or `p->f =` to keep the global in a register; a bare `*p =` (or a `char`/u8 store) to force the reload. Not a register pin. Inertness checked: b differs (one `lw` fewer).
