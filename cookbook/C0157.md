# Small switch compare tree: write case bodies in the target's block order

Symptom: a switch with no jump table matches except for block order (the case bodies appear in a different order).
Lever: reorder the case labels/bodies in the source to the order the target emits them (W12 rock_09 EBBD4: descending 3, 2, 1, 0 took 33 -> 64 of 64). The m2c scaffold's case order (3, default, 2, 1, 0) hinted at it.
