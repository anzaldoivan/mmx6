# C0287 — Overlay-local data names link via PROVIDE. Inside an INCLUDE_ASM blob add // ignore:True
tags: rename,overlay,link,provide,splat,ignore,symbols · date: 2026-10-30 · phase/task: 2.4/T2 · origin: mmx6 T2.c1

Since 2.4/T2 the Makefile `build/%.elf` PROVIDE awk reads `config/symbols.SLUS_013.95.txt` and `config/symbols.<prog>.txt`.
It PROVIDEs every named symbol a `.o` leaves undefined (`U`), at the symbols-file address. That is the D_ address, so it is byte-neutral.

To name an overlay data word:
1. `rename.py --from config/symbols/basis.tsv` after adding the basis row (M19). It writes the line to `config/symbols.<prog>.txt` and renames the src users.
2. The address may sit inside a c subsegment's text-section data (a blob `INCLUDE_ASM`-ed by a .c unit, e.g. rock_16 E9860.c).
   Then end the symbols line with `// ignore:True`. Without it splat 0.50 treats the user symbol as a split point.
   The existing-file .s (e.g. `asm/rock_16/nonmatchings/E9860/func_800F0DDC.s`) stops at the name and the bytes after it are dropped.
   The link passes, but `<bin>: FAILED` and the hash goes red.

   With `ignore:True` splat skips the symbol (no split). The awk still reads the line, so the name still links.
3. Plant-test a new kind of name with fleet-quick first (`FLEET 57 of 57 (quick)` and `PROVIDE(<name>` in `build/<prog>.provide.ld`). Then revert the plant.
4. Rerun `ledger.py --build` and `debt --update` after the rename (C0280).
