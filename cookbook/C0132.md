# C0132 — Plant a missing input for a self-test by planting it whole, proving the hash, then removing it
tags: self-test,control,plant,index,missing-input · date: 2026-10-04 · phase/task: 1.8/T3 · origin: mmx6 campaign

- To test a tool's "missing input" path without breaking the build: plant the full input, prove the binary hash and regenerate the index, then remove the input.
- The index keeps the stale row, so the tool under test sees the input as missing; restore and re-prove the hash after (extends C0066, C0068) (1.8/T3).
