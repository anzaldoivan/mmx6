# C0155 — Range-test register swap: inner difference as x = a then x -= b in a block local
tags: lever,range-test,regalloc,local,difference · date: 2026-10-06 · phase/task: 1.8.1/T11 · origin: mmx6 W11 rock_04 F1B50

Symptom: a range test on a field difference (`if ((u32)(a - b + K) < N)`) gets the right instructions with the operands in swapped registers. Numeric pins and volatile reads do not combine.

Lever: compute the inner difference as a block local. Initialise the local from the field and then decrement it in place: `s32 x = p->f; x -= q->g;`. The two-statement form changes the pseudo order that the allocator sees and fixes the register choice of every range test that shares the shape. For an argument move order residual after a call, give the call result and the shifted term fresh block-scope locals.

Case: W11 rock_04:0x800F1B50 (T11.c69, retry of c29: 93 → 95 → 104/104).
Related: C0144 (abs range test as nested ifs), C0151 (compare operand order).
