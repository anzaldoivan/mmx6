# C0058 — Splat can fuse dozens of real functions into one, so check B2 starts strictly inside each function
tags: boundaries,splat,spimdisasm,merge,bound2 · date: 2026-10-01 · phase/task: 1.6/T1 · origin: mmx6 T1

splat/spimdisasm can fuse dozens of real functions into one undeclared asm function. This is the C0048 farthestBranch effect, with up to 88 per function here. A boundary oracle that checks only phantoms and truncations misses it. Check every independent start found strictly inside each inventory function. Class each start by crossing control-flow edges (branch, fallthrough, jtbl target). A crossing edge means multi-return (keep), and no crossing edge means over-merge (split by declaring sized starts).
