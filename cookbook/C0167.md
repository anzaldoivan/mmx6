# Switch case-tree pivot: an empty `case 0: break;` moves gcc's binary-tree pivot

Symptom: a small switch whose compare tree has one node too few or the wrong pivot value (length or jump residual), e.g. the target splits at 1 and ours at 2.
Cause: gcc 2.95 builds the case tree from the case set; an extra empty case changes the set and so the pivot and node count.
Lever: add `case 0: break;` (an empty case that falls out) to the switch; it costs no code but reshapes the tree (3 → 4 nodes here). Apply to every switch of the same shape in the body.
Evidence: W14 rock_15 F0A78 (24 → 161/164; with a mod-4 spelled `t - (t / 4) * 4` on a block-local s32 → 164/164).
Related: C0156 (`switch ((u32)x)`), C0157 (case bodies in block order), C0113.
