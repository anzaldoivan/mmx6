# C0113 — Linear compare chain in retail is an if/else-if chain, not a switch
tags: lever,switch,if-chain,dispatch,case-tree,block-order · date: 2026-10-03 · phase/task: 1.8/T13 · origin: mmx6 W4

1. **Residual (tell)**: retail compares a small, irregular case set one value after another (a linear chain of equality branches in source order); the draft's `switch` emits a balanced compare tree (or a range node), so block order and the score collapse.
2. **Mechanism**: observed, not source-proven. gcc 2.95 lowers a sparse switch through its case-node tree (balanced, consecutive same-label cases merged into one range), never a linear chain; an if/else-if chain keeps the written order.
3. **Lever**: write the dispatch as `if (x == A) … else if (x == B) …` (or `||` for shared bodies) in retail's compare order; for a masked dispatch (`x & 0xF0`) likewise. If an inner switch's tree pivots differently from retail, give consecutive same-body cases separate bodies so they are not merged into one range node.
4. **Byte proof**: wave W4 (1.8/T13), rock_08:0x800F0200 51 → 271/271 and rock_10:0x800F44A0 261/261 (both banked).
