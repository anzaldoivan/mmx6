# C0177 — Signed /16 with the shift before the sign branch: q = v >> 4; if (v < 0) q = (v + 15) >> 4
tags: lever,division,shift,rounding,signed · date: 2026-10-10 · phase/task: 1.8.1/T17 · origin: mmx6 W17 rock_08 EB098

Symptom: of two adjacent signed `/ 16` scalings, the draft compiles both the same way, but retail computes one shift before the sign branch and then a rounded shift on the negative arm.
Cause: gcc's own `/ 16` emits add-then-shift; the shift-first form comes from source that spells the rounding by hand.
Lever: for the scaling whose target shows the double shift, write `s32 q = v >> 4; if (v < 0) q = (v + 15) >> 4;` in an s32 local; keep plain `/ 16` for the other. The m2c scaffold's spelling tells which is which.
Evidence: W17 rock_08 EB098 (32/66 to 66/66; banked after declsync).
Related: C0146 (operand order follows spelling).
