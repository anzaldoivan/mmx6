# Move an in-place restoring self-test off the serial chain: run it in a scratch tree and sha1-guard the real one

- Move (3.1 T11): a self-test that edits src/, the registry, the corpus and the exe and then restores them must run alone. If its paths are cwd-relative, copy the tree to `.run/<tool>/tree` (the propagate.make_tree pattern). copy2 and copytree keep mtimes, so make sees build/ as current. Then chdir into the copy and run the old body there unchanged.
- Copy only what it reads. Skip other rungs' build/ outputs. Parallel rungs write build/ at the same time, so tolerate files that vanish mid-copy. extracted/ is a symlink. family_remap: about 135 MB, about 1 s.
- Guard: hash the real src/, include/, registry, build/corpus and exes before and after the run, and fail closed with the path. Prove the guard with a plant: a new one-byte file under src/ must be the only path flagged, then remove it. A new file, not an edit, so parallel readers never see a half-changed source.
- Declare every build/ input as a prerequisite (bank R5's sig.py --rescan reads build/sig, so th-sig).
- Wall: the rung went from 160 s alone to 408-492 s beside th-harness, but it ends before th-harness, so it is off the critical path. Health fell from 699-709 s to 655 s.
- Trap: a scratch rebuild against a container build/ older than src/ fails to link (`undefined reference .L…`). Run such self-tests only after a fleet or a `make build`.
