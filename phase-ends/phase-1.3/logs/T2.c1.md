## Choices
- bss starts at file end 0x8008F000 (not 0x8008EAA8, where startup clears): the tail 0x8008EAA8..0x8008F000 is emitted as file data in 6D5D0.data.s.
- build = sub-make `build-bins` so `$(shell find asm/<bin>)` is read after split in `make split build`; every .s.o depends on its .s + include/macro.inc.
- `.DELETE_ON_ERROR:` added: without it a failed sha1 leaves build/SLUS_013.95 up to date and a second `make build` exits 0 (gate hole). Verified rerun stays red.
- symbols file: splat 0.50.0 parses `key:value` tokens in a trailing comment as attributes (`basis:` → "Missing attribute value in 'basis:'", first run, .run/logs/t2-build.log overwritten); basis goes on the comment line above each symbol. generalizable: splat symbol_addrs trailing comments must not contain `word:` tokens.
- ASFLAGS `-EL -march=r3000 -mtune=r3000 -mabi=32 -no-pad-sections -G0 -Iinclude`; ld with `--no-check-sections`, undefined_*_auto as extra -T.
