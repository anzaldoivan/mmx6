# dumpsxiso -x puts non-ISO files in the output dir

dumpsxiso writes `license_data.dat` (the system area) inside its `-x` directory (and Track 2 audio as `*.WAV` for `da`
entries on discs that have a CD-DA track — Mega Man X6 is a single data track, so expect only `license_data.dat`).
Move them out before diffing against an ISO-tree extractor, or the diff reports them as Only-in.
