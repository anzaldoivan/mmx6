# C0111 — If/else arms each storing a field via a pinned block local cross-jump into one store
tags: lever,if-else,cross-jump,jump2,delay-slot,clamp,register-pin · date: 2026-10-03 · phase/task: 1.8/T12 · origin: mmx6 W3

1. **Residual (tell)**: A clamp/select stores one field from two arms. Retail has the constant arm in a branch delay slot. Retail also has a single shared store with the value in the return register. The draft presets the value, then overrides it, and stores once from another register.
2. **Mechanism**: This is observed, not source-proven. `x = v; if (c) x = K; p->f = x;` (or a ternary) folds to preset-then-override. As a result, there is no arm to steal into the delay slot. With the value in a block-scope register-pinned local, two arms that each store the field themselves stay separate. Then jump2 cross-jumps the identical store tails into one. This leaves the constant load where reorg can fill the delay slot.
3. **Lever**: Write the clamp in its own block: `{ register s32 m asm("$2"); if (v >= 6) { m = v; p->f = m; } else { m = 5; p->f = m; } }`. Pin the register that the retail store uses. Keep the stores of both arms textually identical so that they merge.
4. **Byte proof**: In wave W3 (1.8/T12), rock_02:0x800F0F4C went 61/64 → 64/64 (banked).
