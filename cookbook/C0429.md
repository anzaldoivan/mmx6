# diff.sh under `mx.sh run` needs `--no-pager`
- Symptom: `mx.sh run bash tools/mmx6/diff.sh <func>` prints `DIFF <func> ? differing lines`.
- Mechanism: no TTY under `docker run` without `-t`, so asm-differ starts the `less` pager, absent from the image.
- Fix: `mx.sh run bash tools/mmx6/diff.sh <func> --no-pager` (extra args pass to asm-differ) -> `DIFF <func> 0 differing lines`.
- Seen 2026-11-09, 3.0 T17.c1 (func_8004FF7C).
