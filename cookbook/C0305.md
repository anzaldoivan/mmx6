# C0305 — Repoint a bare cite split across files: choose the file holding prog:0x<vram> on the same line
tags: layout,repoint,cite,vram,dedup,bare · date: 2026-10-31 · phase/task: 2.4/T15.1 · origin: mmx6 T15.1.c1

Context: layout.py repoint_text (2.4 T15.1.c1). config/dedup_registry.txt had 1226 bare role paths.
- A cite without a line number maps only when all its move rows share one destination.
- Otherwise look for a `prog:0x<vram>` on the same line. Locate that vram on the current tree (where_of).
- With no vram on the line, report the cite unmapped.
- Fix unmapped lines (docconv sidecars) by hand with layout.locate of the named function.
