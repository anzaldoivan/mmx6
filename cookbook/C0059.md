# C0059 — Code after an interior jr ra reached by no edge is its own function; splitting is byte-neutral
tags: boundaries,mips,multi-return,merge · date: 2026-10-01 · phase/task: 1.6/T1 · origin: mmx6 T1

Code after an interior `jr $ra` (and its delay slot) that no branch, jump table or fallthrough of the enclosing function reaches is a separate function. Declaring it sized in the symbols file is byte-neutral. Complement of C0049 (multi-return): only crossing evidence keeps code merged.
