# C0066 — Plant a self-test precondition that real progress consumed; prove the plant by the binary hash
tags: self-test,control,plant · date: 2026-10-01 · phase/task: 1.6/T6.1 · origin: mmx6 T6.1

When a self-test needs objects that real work has since banked (e.g. asm siblings), plant them: revert real C to INCLUDE_ASM over a generated `.word` .s of retail words, rebuild and require the pre-test binary sha1, run the controls, restore byte-exact and check the tree, registry and binary sums. Never borrow another live class (C0054).
