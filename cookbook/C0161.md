# A branch delay slot holding a call's argument constant: pin the argument before the test

Symptom: the target's `bnez` delay slot loads the call's first-argument constant; ours fills it from the fall-through block's first instruction (another constant store).
Cause: in the target the constant load sat before the branch and reorg filled the slot backward.
Lever: in a block around the if, declare `register s32 a asm("$4")`, read the tested field into an s32 local first, assign `a = <const>;` before the test, and pass `a` to the call. A plain local is constant-propagated (no effect); a pin assigned inside the if has no effect.
Evidence: W12 rock_02 F87FC (c50 62/64 -> c68 64/64).
Related: C0136 (do-while(0) barrier), C0141.
