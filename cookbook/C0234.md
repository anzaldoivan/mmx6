# Block-scope extern before file-scope extern: gcc 2.95 order rule
- gcc 2.95 accepts a block-scope extern array declaration followed later in the TU by a file-scope extern of the same name.
- The reverse order fails with conflicting types.
- A banked body inserted early in a TU must use block-scope spelling when a later body declares that name at block scope with another type.
