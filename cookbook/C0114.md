# C0114 — Unaligned 4-byte table copy is __builtin_memcpy with u8 pointers
tags: lever,memcpy,unaligned,copy,builtin,length · date: 2026-10-03 · phase/task: 1.8/T13 · origin: mmx6 W4

1. **Residual (tell)**: retail copies 4 bytes from a data table with unaligned left/right word loads and stores; the draft (int read, struct copy, or byte loop) emits aligned loads or byte moves, changing length.
2. **Mechanism**: observed. gcc 2.95 expands a constant 4-byte `__builtin_memcpy` between `u8 *` operands (alignment 1) inline as an unaligned word move, with no library call and no struct definition (draft.c may not define structs, bank R3).
3. **Lever**: `__builtin_memcpy(dst, src, 4)` with both operands typed `u8 *`.
4. **Byte proof**: wave W4 (1.8/T13), rock_11:0x800EB1B8 135/135 (banked; main lever there was C0109).
