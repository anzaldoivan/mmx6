# A numerically pinned arg-register local for a global passed to an unprototyped call

Symptom: the function copies a u8/s8 global to another global and passes it to an unprototyped call. A plain or u8 local double-loads or adds a `move`.

Lever: write `register s32 v asm("$4") = GLOBAL;`. Then write the store and the call with `v`. `v` is an s32 local pinned to the first argument register.

Cases: W22 rock_05 0x800F1788 (50/50) (T22.c37). The same pin family closed the hp constant ($2) of rock_05 0x800E9CF8.

See also: C0141, C0161, C0179.
