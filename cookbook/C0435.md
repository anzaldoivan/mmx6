# Alias an undefined link symbol in C with a top-level `__asm__("U = N");`
- Symptom: R5 link `undefined reference to update_<boss>`. A shared body calls a name that the member program spells another way (its own name for the same dup class).
- Lever: append `__asm__("U = N");` to the referencing unit, where N is the member program's symbol. The relocations then land on N, which was checked with readelf in the container.
- Trap: `.set U, N` does not work on MIPS gas. There `.set` is the option directive (`.set noreorder`, `.set at`), so use the `U = N` assignment form.
- Case: 3.1 T3.c2, the rung5_unify step of the declunify switch (rock_33, rock_34, rock_35 link rows).
