# C0128 — A sibling decomp's vendored SDK headers are not covered by its license: re-express API types yourself
tags: license,sdk,psyq,headers,prior-art,firewall · date: 2026-10-04 · phase/task: 1.8/T7 · origin: mmx6 W-x4

- A decomp licensed AGPL does not license the Sony SDK headers it vendors (include/psy-q-*).
- Before porting bodies that use SDK types, write those types from interface facts into your own header (here include/mmx6/psyq_api.h); never copy the vendored text (1.8/T7, G102).
