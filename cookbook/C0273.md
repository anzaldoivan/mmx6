# Naming PsyQ lib functions from placed objects: reloc cross-check, trivial objects, no statics

- Placement: per `lib` row, find the offset in the object's .text where the row span matches retail masked. Name the object's globals at base+value.
- Masked match is not identity: identical stubs (C0241) and wrong rows pass it. Cross-check each text reloc whose target global the table names elsewhere: the retail word must decode to that address. In mmx6 2.3/T3 this refused 3 boundary rows (SSSNC, S_IH, PLAY), each named correctly by another row.
- Trivial objects (no relocs, only `jr ra` + `nop`, e.g. LIBSND VM_VIB) match anywhere, even inside a game function. A trivial object placed more than once names nothing unless exactly one placement sits on ledger function starts.
- psyq-obj-parser ELFs carry no local text symbols: static library functions stay unnamed (about 104 of 488 lane starts in mmx6).
- Aliases: one address can carry two globals (2MBYTE `__SN_ENTRY_POINT`/`stup2`): pick by a fixed rule and record the other.
