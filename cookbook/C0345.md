# Reformatting src/ shifts `code:<path>:<line>` anchors, so repoint them in the same commit

Residual: after a bulk `make format`, `namesqueue check` refuses rows with `code-anchor-missing`.
`docconv check` (th-selftests-cheap) fails DC4 on `// basis: code code:...` doc headers.

Mechanism: line-anchored refs in `config/symbols/basis.tsv`, `config/names-verdicts.tsv` and src doc headers
point at lines that InsertBraces, macro wrapping or removed blank lines moved.

Lever: formatting never reorders tokens. Map each anchor HEAD→new by the k-th occurrence of its anchor text in
the file, then rewrite the line number. Run `namesqueue check` and `docconv check` before the fleet.

Proof: in 2.6/T2.c1, 11 refused rows became 800 of 800 judged (rc 0). DOCCONV OK. FLEET 57 of 57.

Note: `config/x4/renames.tsv` carries such refs too. It is an unchecked history ledger, so leave it.
