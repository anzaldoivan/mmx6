## Implementation choices (within brief)
- B2 computed for all 57 programs every run (exe jal starts need overlay bodies); --prog only selects output/report.
- jtbl-label "adjacent": key word / problem run [x,y) with x <= hi and lo <= y (abutting counts); unknown-hi row = word [lo, lo+4).
- truncation problem runs = words with coverage != 1, plus [inv_end, b2_end) when the inventory fn at s ends early.
  data-tail = all coverage-0 words of the truncation inside corpus data|pad spans (needs >= 1 uncovered word).
- q1-text-end: exe, problem run intersects [0x8006D5D0, 0x8006D5D8).
- CLASSES counts unledgered disagreements only; ledger keyed (prog, vram, kind); stale rows printed `BOUND2 STALE`.
- Self-test: split/cut pool = agreeing fns with b2 end == inv end and >= 3 words, func_80055A04 first. 80055A04
  agrees but was not picked for the split (falls out of the pool, likely b2_end != inv_end, i.e. trailing pad);
  split used 0x8001e78c, cut 0x800473ec (brief allows another agreeing fn).
