# Hoisting a struct-typed global's extern hides its member reads from objfields

- Context: extern sweep into include/mmx6 headers (C0331, C0332).
- Wall: `objfields.py --census` types `v.m` accesses only through a file-scope declaration of `v` in the same file. Removing `extern struct X4_PlayerObj g_Player;` from a .c file (now declared via header) leaves its `g_Player.m` reads uncensused -> bad note (e.g. `PlayerObj.nova_strike_active`) -> `OBJFIELDS CONTROL FAIL clean` in fleet health.
