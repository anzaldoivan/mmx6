## Problem
A multi-seed permute.py pass (C0373) ends with best = base on every seed. That looks like C0373's inf-death. It may instead be a live walk that never beats a close base.

## Move
- Before reading "best = base" as a wall, grep one seed's permuter.log: count error and `inf` lines, and note the mutation score range.
- Live walk (0 errors, no inf, mutations far above base): random permutation does not reach this near-miss. Record `permuter 12x100: base N best N` in the Blockers row and spend no more permuter time on it. The residual needs a structural lever (loop, sched, regalloc), not statement order.
- Dead walk (inf): C0373 applies, so use shorter seeds.
- The macOS host has no `timeout`. Cap each attached seed with a sleep/kill watchdog. A TERM to `mx.sh run` stops its named container through the script's trap.
