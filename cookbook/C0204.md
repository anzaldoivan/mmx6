# A plain while loop where m2c's if + do-while materialises a global's high base twice

Symptom: a length residual of one instruction (80/81) on a loop whose test indexes a global table by another global. The m2c shape `if (cond) do { … } while (cond);` makes gcc build the table's high base twice: once for the guard, once for the loop test.

Lever: write the loop as a plain `while (cond) { … }` and let gcc invert it itself (its copied guard shares the base with the loop test). The converse of C0087: when retail's guard and exit test share one base, the plain while is the source shape.

Seen: W26 SLUS_013.95 15C5C (T26 c28, 81/81).
