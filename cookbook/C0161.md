# C0161 — Delay slot holds a call-arg constant: pinned arg-register local set before the test
tags: lever,delay-slot,reorg,register-pin,call,argument · date: 2026-10-09 · phase/task: 1.8.1/T12 · origin: mmx6 W12 rock_02 F87FC

# A branch delay slot holding a call's argument constant: pin the argument before the test

Symptom: the target's `bnez` delay slot loads the call's first-argument constant. Our build fills it from the fall-through block's first instruction (another constant store).

Cause: in the target, the constant load sat before the branch and reorg filled the slot backward.

Lever: in a block around the if, declare `register s32 a asm("$4")`. Read the tested field into an s32 local first. Then assign `a = <const>;` before the test. Pass `a` to the call. The compiler constant-propagates a plain local (no effect). A pin assigned inside the if has no effect.

Evidence: W12 rock_02 F87FC (c50 62/64 -> c68 64/64).
Related: C0136 (do-while(0) barrier), C0141.
