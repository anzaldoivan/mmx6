# C0103 — Unused-result call cast to (void) splits or merges identical call arms (jump2)
tags: idiom,sym-cross-jump,G-jump,jump2,cross-jump,call,void-cast · date: 2026-10-02 · phase/task: 1.8/T9 · origin: mmx6 W0

1. **Residual (tell)**: Two or more `switch`/`if` arms each end in the same call. In the draft, these arms are one shared call block. In the target, they are separate calls (or the reverse). Or the draft is short by a few words around unused-result calls. `sym-cross-jump`
2. **Mechanism**: This is observed, not source-proven. Casting the call to `(void)` (or calling through a void-returning function-pointer cast) changes the call's RTL (no return-value set). Then jump2's cross-jumping stops treating the arm tails as identical. The reverse spelling restores the merge. Related: C0083 (which tails merge).
3. **Lever**: For an unused result, write `(void)f(x);` or `((void (*)())f)(x);`. When the target merges the arms, drop the cast. Try it per call site, not per TU.
4. **Byte proof**: Manual wave W0 (1.8/T9) has probe-pack matches (banked unless noted) where this lever was a closing lever. The matches are rock_03:0x800EE5CC 80/80 (bank stopped R4, plumbing), rock_05:0x800EA750 102/102, rock_02:0x800F59C0 40/40 (38→40) and rock_06:0x800ED09C 645/645. The levers are live per `harvest.py --inert-wave W0`.
