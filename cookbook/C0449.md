# A fresh volume for refusecause or cards.py --wave: extract, build, corpus, census, sig first

A new `MX6_VOLUME` (or a /work whose build/ was cleaned) lacks the post-build scanner outputs the campaign tools read.
Order: `mx.sh sync`, `mx.sh run make extract` (a fresh volume has no extracted/, `make build` fails rc 2),
`make build`, `python3 tools/mmx6/corpus.py --all`, `python3 tools/mmx6/census.py --all`, `python3 tools/mmx6/sig.py --all`.
- Without build/census/classes.jsonl, `refusecause.py --prog P` exits rc 0 in about 1 s. Every row's cause is `error`.
- So rc 0 proves nothing. Run one program first (rock_18, 245 s) and check its output holds no `error` cause.
- `cards.py --wave` stops with FileNotFoundError build/sig/twins.jsonl when sig.py --all has not run.
Measured 3.1 T16.c1 (mmx6-t16) and T16 (mmx6-work). Related: C0250 (x4share needs the same sequence).
