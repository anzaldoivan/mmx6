# C0153 — A joined value stored to a narrow field lives in an s32 local. A u8/u16 local adds a mask
tags: lever,local,s32,zero-extend,mask,join,byte · date: 2026-10-06 · phase/task: 1.8.1/T10 · origin: mmx6 W10 rock_09 ECC10

Symptom: the code computes a value in two arms (or a goto-joined block) and stores it to a byte or halfword field. In the draft, the value carries one extra zero-extend/mask at the join. The length residual is a word or two.

Lever: declare the local of the joined value as `s32`, not `u8`/`u16`. The narrow store truncates anyway, so retail never masks. The same holds for a counter temp: `s32 t = field + 1; field = t; if ((s16)t == K)` instead of a u16 temp.

Case: W10 rock_09:0x800ECC10 (T10.c54, 53 → 58/58), rock_09:0x800F3A58 (T10.c61, temp as s32 dropped the mask).
Related: C0119 (s16 to s32 before negate), C0142 (one reused s32 local).
