# Bank a SLUS wave draft from src/shared, not from waves/

Problem: `bank.py <prog:vram> --src waves/W<n>/<pack>/draft.c` includes whatever --src points at, so the unit #includes an ignored waves/ path (3.2 T5.c1 first round, and 3.1 T15 saw the same).

Recipe (3.2 T5.c1, W306, 12 banks, and W305 commit 67971585 did the same):
- copy the draft to `src/shared/<prog>/func_<X>.c` first. Bank with `--src` that path, `--repair relocdef --repair unitcut`
- typecheck refuses under src/shared: local typedefs ("outside") and raw `*(T*)0x1F80....` scratchpad casts. Hoist types to `include/mmx6/types.h`, use `SP(off)`
- a new header type raises typecheck's self-test header shape count (tools/mmx6/typecheck.py:351): bump it with a provenance note. Otherwise the fleet's th-selftests go red
- run `ledger.py --drop-banked` (and pull campaign/ledger.tsv) BEFORE the fleet: th-ledger fails while banked rows are still listed.
- declsync refuses a return-type mismatch even through an unprototyped `((s32 (*)())f)(...)` cast when the callee is defined void (80018774 stop, compare C0386's width rule)
