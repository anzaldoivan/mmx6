# Assign a call-free local after the call's early-return test, not at function entry

- Symptom: a value assigned before a call and used after it stays live in a callee-saved register.
- A pointer local set at entry has its address build hoisted before the first call.
- Retail builds the value late. rock_07 F036C sets its state constant after the call and its early-return test. The value then lives in the return register.
- rock_20 EAE98 builds the engine base pointer between the two callees.
- Lever: move the assignment to just after that call or test. Do not initialise the local at the top.
- Opposite case: C0186 sets the constant in a block local before the first call, because retail keeps it callee-saved. Check which case retail shows.
