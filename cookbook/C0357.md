# Insert DC1 banners before `layout.py repoint`, or shift every `path:N` cite after

Context: a layout apply moves member files. Then you add or replace a DC1 `system <name>` banner line at the top of
each file, and you repoint the cites.

Trap: a banner adds one line to the file. Every `path:N` cite into it then points one line too high. This includes
basis.tsv, symbols, renames, names-verdicts and config/types/fields.tsv. Repoint fixes paths, not line numbers.

Move:
- Preferred: write the banners first. Then run `layout.py repoint` and the docconv and namesqueue checks.
- If the banners went in after repoint, use a scratch script. It adds 1 to N for each `path:N` cite into a file that got a
  new line. Do not shift cites into files where an existing banner was only replaced. Skip append-only ledgers.
- Then confirm: `namesqueue.py check` green, `docconv.py check` OK.

Evidence: 2.6/T8.c1 added 62 banners and shifted 143 cites. Result: NAMESQUEUE 919 of 919, FLEET 57 of 57.
