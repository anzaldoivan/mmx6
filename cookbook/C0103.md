# C0103 — Unused-result call cast to (void) splits or merges identical call arms (jump2)
tags: idiom,sym-cross-jump,G-jump,jump2,cross-jump,call,void-cast · date: 2026-10-02 · phase/task: 1.8/T9 · origin: mmx6 W0

1. **Residual (tell)**: two or more `switch`/`if` arms that each end in the same call are emitted as one shared call block in the draft but as separate calls in the target (or the reverse); or a draft that is short by a few words around unused-result calls. `sym-cross-jump`
2. **Mechanism**: observed, not source-proven. Casting the call to `(void)` (or calling through a void-returning function-pointer cast) changes the call's RTL (no return-value set), and jump2's cross-jumping then stops treating the arm tails as identical; the reverse spelling restores the merge. Related: C0083 (which tails merge).
3. **Lever**: for an unused result write `(void)f(x);` or `((void (*)())f)(x);`; drop the cast when the target merges the arms. Try it per call site, not per TU.
4. **Byte proof**: manual wave W0 (1.8/T9) probe-pack matches (banked unless noted) where it was a closing lever: rock_03:0x800EE5CC 80/80 (bank stopped R4, plumbing), rock_05:0x800EA750 102/102, rock_02:0x800F59C0 40/40 (38→40), rock_06:0x800ED09C 645/645; levers live per `harvest.py --inert-wave W0`.
