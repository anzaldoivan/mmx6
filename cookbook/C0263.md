# Hand comments in an adapted src/shared file survive a repin only as `// !` lines

`x4port.py --repin` picks files by the `/* Adapted from sozud/mmx4 @<pin> ...` header (x4port.py:1066-1067, :991-994).
- Header pin equals the current pin: the file is not rewritten (:1037-1042).
- Same code at the new pin: only the header line is replaced, and the body, hand comments included, is kept (:1023).
- Changed code: the body comes from the draft, and only `^\s*//\s*!` mark lines are put back (`keep_marks`, :904, :953-966).
  Any other hand line is lost, including a `// str 0x... = "gloss"` game-string comment.

A hand note that must last has three homes.
- A file without the Adapted header.
- A tracked table such as `docs/leads/strings.tsv`.
- A file held in `config/x4/hold.tsv` (`path pin blocker`).
Files without the header are never touched by repin.
