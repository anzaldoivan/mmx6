# Pin a Docker image by config digest, not image Id, under buildx

- Symptom: `docker image inspect --format '{{.Id}}'` changes between identical builds, or differs from what another host reports.
- Cause: buildx/containerd image store wraps the image in an index with attestation manifests; the Id can be the index digest.
- Fix: pin the base by `FROM image@sha256:<manifest digest>` and record the built image's config digest (`.Config` blob digest) as the reproducibility pin; keep the Id only as an informational line.
