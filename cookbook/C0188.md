# Decimal digit split: let gcc share the quotients

Symptom: a four-digit counter print. The C0110 spelling (explicit quotient local, `v - q*d`) costs one extra callee-saved register and the frame shifts.

Lever: write the digits plainly, `v / 1000`, `v % 1000 / 100`, `v % 100 / 10`, `v % 10`. Let cse share the quotient/remainder pairs.

Rule of thumb: try the plain spelling first. Use C0110 when retail visibly reuses one quotient across a multiply-subtract.

Case: W20 SLUS_013.95 0x800190FC (T20).

See also: C0110.
