# C0477 — A clear loop with the increment in a backward branch delay slot: volatile store, (p++, 1) test
tags: lever,loop,delay-slot,volatile,do-while,pointer,reorg,length · date: 2026-11-15 · phase/task: 3.2/T6 · origin: mmx6 T6.c14 func_80013BD0

Symptom: a tiny store-then-test pointer loop (5 words) has its increment in the delay slot of one backward `bne`.
Plain C forms are a word long or short: the store fills the exit branch's slot and a jump back is added.

Mechanism (reorg): the delay-slot filler will not move a volatile store into a slot.
So it fills the exit branch's slot with the increment, which is harmless on the exit path.
It then folds "branch over a jump back" into one backward branch with the increment in its slot.

Form: `do { *(volatile s32 *)start = 0; } while (end != start && (start++, 1));`
