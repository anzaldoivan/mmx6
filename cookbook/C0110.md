# C0110 — Remainder as value minus quotient times divisor, then divide in place, reuses the quotient
tags: lever,divide,remainder,quotient,regalloc,digits · date: 2026-10-03 · phase/task: 1.8/T11 · origin: mmx6 W2

1. **Residual (tell)**: The code is a digit or unit conversion (`/100`, `%100`, `/10`). Retail does one divide per step and reuses its quotient. The draft's `%` emits a second divide or keeps an extra value live. This shifts the saved-register choice.
2. **Mechanism**: gcc 2.95 does not fold `x % k` into a prior `x / k`. But `r = x - q*k` reuses `q`. A divide of `r` in place (`r /= 10`) keeps one pseudo for the tens. As a result, the allocator lands values in retail's saved registers.
3. **Lever**: Write the remainder as `value - quotient*k` into the next digit's variable. Then divide that variable in place. For time fields, write `minutes = q60 - hours*60` before `seconds = time % 60`.
4. **Byte proof**: In wave W2 (1.8/T11), rock_18:0x800EED18 went 107 → 156/156, banked. In the same wave, rock_18:0x800EDDB4 is at 365/365 (minutes from the quotient), banked. The levers are live by `harvest.py --inert-wave W2`.
