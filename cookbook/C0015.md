# C0015 — GhidrAssistMCP headless: stop via completion_file so the project saves. A kill of the JVM skips the save
tags: ghidra,mcp,ghidrassistmcp,headless,save · date: 2026-10-01 · phase/task: 1.2/T2 · origin: mmx6 T2

When the file that its `completion_file=` option names appears, the headless wait mode of GhidrAssistMCP ends cleanly. It saves the program and releases the project lock. A kill of the JVM (pkill/SIGTERM) skips the save. Import/export need the server stopped (project lock).
