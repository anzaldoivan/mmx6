# C0117 — A splat blob whose fields retail loads by fresh high-half is several globals: one extern per field
tags: lever,splat,blob,extern,cse,hi-lo,global · date: 2026-10-03 · phase/task: 1.8/T13 · origin: mmx6 W4

1. **Residual (tell)**: retail loads each field of a large splat data symbol with a fresh high-half address load per field; the draft, declaring the symbol as one array or struct extern, folds all fields onto one base register (shorter, wrong registers).
2. **Mechanism**: observed. A splat blob (one `D_<addr>` spanning many original globals) is really several globals; cse shares one base for offsets of one symbol, but not across distinct symbols.
3. **Lever**: declare each used field as its own `extern T D_<addr>;` (the linker script's provided symbols define them) instead of offsets into the blob.
4. **Byte proof**: wave W4 (1.8/T13), rock_20:0x800EA1F0 548/548 (banked at the W4 regate).
