# C0047 — Once a function is C, splat writes no nonmatchings .s for it. Extent tools must fall back to symbol order
tags: splat,nonmatchings,extent,probe · date: 2026-10-01 · phase/task: 1.4/T8 · origin: mmx6 T8

Tools that read a function's extent from asm/<bin>/nonmatchings/<tu>/<f>.s lose it as soon as you bank the function as C. Fall back to symbol order (function start to next function start, trimmed per C0021).

Source: phase 1.4 T8 (probe.py find_extent fallback).
