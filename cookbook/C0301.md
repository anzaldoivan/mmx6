# A tool that finds a C definition by a name regex must require the `{`: role files carry prototypes

- Under one-function-per-file a body file held one definition and the walk never met prototypes (they sat in
  `src/shared/`, which the walk skipped). Under L-B a role file under `src/<prog>/` carries prototypes of functions
  defined in other role files (`void func_8001E78C(void);`).
- `^\w[^;(]*\bfunc\(` matches a prototype. `probe.find_extent`'s C-banked fallback walked `src/SLUS_013.95/`. It hit
  `new/new_game.c:82` first and returned a 288-word extent instead of the corpus's 13. family_remap's self-test
  then failed `plant 34B vs corpus` (2.4/T15.c2, full fleet th-remap).
- Fix: definition only, `^\w[^;(]*\bfunc\([^;]*?\)\s*\{` (`tools/mmx6/probe.py`, the walk's filter line).
- Check: grep each tool for a name regex ending at `\(` before a regroup. `layout.locate` is the locator to prefer.
