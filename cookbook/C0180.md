# sym+K row base kept split by an s32 offset local, and the per-arm loop body as a macro argument

Symptom: retail keeps `lui/addiu sym; addiu +K` (an add on the table register) inside or before a loop. The draft folds
it into one `lui/addiu %lo(sym+K)`.

Cause: `sym + K` folds at expand time, and cse barriers do not split it.

Lever: put K into an s32 offset local in the loop body: `off = K + i*4; *(T*)((s8*)sym + row*S + off)`.
Two arms of one shared macro may need different offset-local terms (`row*S + K` vs `K + i*4`). This is because loop.c's
hoist threshold (`threshold * savings * life >= insn_count`, T = 58 measured for that TU) differs per arm. Pass the loop
body as a macro argument so each arm keeps its own spelling. Which terms the local holds decides whether loop.c hoists
the divide magic constant.
