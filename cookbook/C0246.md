# C0246 — Pin inside a macro body: depin nocompile, floor counts per use, mark each use line

When: a depin sweep's .out ends `final nocompile` (no `DEPIN <func> pins a to b`) and the file is unchanged.

- Cause (1.10/T3, rock_02 func_800EECAC `SET_ANIM`, func_800EF804 `SET_ANIM2`): the pin `asm("...")` sits in a backslash-continued `#define`.
- Depin's `//` marker inside the continuation breaks the compile, so depin leaves the file as is.
- The floor reads the cpp output. One macro pin counts once per line that uses the macro (3 uses = 3 pin-unmarked).
- Fix: put a standalone `// !FAKE: depin: macro pin, drop breaks match (<m>/<n>)` line above each use line.
- Take m/n from the drop trial in the .out file.
- Then run `psxd_floor.py debt --files` and a clean rebuild (comment-only, must hash OK).
