# Labelled RAM poke as a pad-schedule stimulus. A poke of a mode id does not load its overlay

Problem: a behaviour needs a state that the pad cannot reach in ~1 min of the intro stage (low health, another armor).

Move:
- The schedule carries `pokes = {{frame, field, value, label}}`. The watcher writes each poke as its own dp line (`fn = poke`). The doc then cites the stimulus beside the effect (mmx6: hp 32 -> 4, then one hurt starts the low-health timer).
- Some fields select code that lives in an overlay (mmx6: the armor id, with action 35 at 0x801EB8B8 in the overlay at 0x801EA000). A poke of such a field changes the branch but does not load the overlay. The dispatch then jumps into stale code.
- Example of the trap: armor 1 -> 3 gave action 74, and the dispatch stopped within 20 frames. Treat such a run as invalid, not as behaviour. Reach the state with a savestate or the real route.

Example: tools/mmx6/redux/inputs/mv_lowhp.lua, mv_ceiling.lua (2.6 T6.c1).
