# C0063 — Format a body before the first probe; clang-format changes its sha1 afterwards
tags: clang-format,bank,sha1 · date: 2026-10-01 · phase/task: 1.6/T4 · origin: mmx6 T4

When a body file's sha1 is the invariant across a bank ladder, run the project's formatter on it before the first rung. Here clang-format rewrote unknown-typedef pointers (`s8* x`), which would change the sha1 between R1 and R5.
