# Regalloc cues: a leftover argument register is a shorter call, and a hoisted %hi means in-loop code
- A value left in `a2`/`a3` at a call can mean the callee takes fewer arguments than m2c shows. Call through a cast with that many arguments instead of pinning the register. Seen: T26.c4 `DecDCTvlc` (2 args, the `$6` pin went away) and T26.c3 `set_animation` (2 args).
- `%hi` halves and index products hoisted above a wait loop, for code that runs after it, mean the code sat inside the loop. Move the stores into the loop with a `for(;;)` / `continue` / `break` shape (T26.c4 wait_for_file_load).
- Trap: that loop shape can hoist the whole address too, so score each step on the in-place build (C0388).
