# Rodata-first overlay: cut rodata into gaps so splat pairs the table
- In an overlay laid out rodata-first, splat sees the leading rodata as a data chunk named after the base, inside the C unit.
- Cut the table into a unit-rodata gap plus a rodata piece for the unit, so splat pairs the table with the unit.
- Strip the size attribute from the data symbol. Otherwise the disassembler never splits out the table labels.
