# C0472 — A retail lbu then a redundant andi 0xff before a test: duplicate else-if arms, wide local cast
tags: lever,mask,andi,lbu,combine,zero-extend,else-if,cross-jump,jump2,local-reuse · date: 2026-11-15 · phase/task: 3.2/T6 · origin: mmx6 T6.c8 func_80030ECC

Symptom: retail loads a byte unsigned and then masks it again with `andi 0xff` before a compare.
Our draft drops the mask, so it is one word short.

Mechanism (dumps, combine): combine deletes the zero-extend when the load and the test sit in the same label tick.
This holds even for a local assigned twice, so C0417 alone does not keep the mask.

Lever: write the test as an if / else-if chain, with the shared arm (`= 4`) written out in each branch.
Each `else` is a code label during combine, so the mask survives.
jump2's cross-jumping then merges the duplicate arms, so retail's asm shows no label.
Put the byte in a wider local that is assigned twice (`s32 t2`) and cast at the test: `(u8)t2 == 5`.
The choice of local also picks the register: another reused local scored 257/260.

Evidence: 3.2 T6.c8 func_80030ECC went from 259/260 to 260/260 pin-free, in 11 probes and 2 dumps runs.
