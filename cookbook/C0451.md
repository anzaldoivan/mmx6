# C0451 — Drop several pins on a plateau: per-arm barrier tails, a reused local, one shared pointer
tags: lever,pin,depin,register-pin,jump2,cross-jump,do-while,local-reuse,rematerialise · date: 2026-11-12 · phase/task: 3.1/T17 · origin: mmx6 T17.c3 rock_09 func_800E9EF0

## Problem
A plateau draft matches only with several register pins (arg-register and v0/v1 locals) on constants,
a per-arm tail and a global's address. Each pin alone resists removal (depin `pins 4 to 4`).

## Move
- Per-arm constant tail (`li K; sh`): end each if/else arm with `...; do {} while (0); n = K; field = y;`,
  so jump2 merges the tail into the join block (C0138, C0111, barrier C0136). It drops the tail's pins.
- One reused s32 local carries the first constant then the next value (C0142). This drops the constant pin.
- Both table addresses go through one reused pointer local.
- A single-use constant address (`&D_xxx`) left unpinned is rematerialised at its use: statement order
  cannot move it. Reusing a multi-set local for it gets close (158/162). Otherwise keep its one pin.
