# C0134 — Gate-tool-safe body spellings: #define for absolute addresses, prototyped params, numeric register pins
tags: typecheck,declsync,verbatim,register-pin,k-and-r,regex · date: 2026-10-04 · phase/task: 1.8/T10 · origin: mmx6 W1-W2

- typecheck refuses raw absolute-address casts only under src/ (a body under .run/ passes): spell scratchpad accesses through a `#define` (1.8/T10).
- A K&R definition defeats declsync's definition regex (the gate prepends a wrong define, nocompile): use prototyped params plus narrowing locals (1.8/T10).
- verbatim accepts register pins only as `asm("$8")`; `asm("t0")` is refused as inline asm (1.8/T11).
- verbatim refuses a pin on a function-pointer declarator (`register void (*fn)(…) asm("$5")`): pin a `void*` local and cast at the call, `((void (*)(T*))fn)(self)`; same code (1.8.1/T6, rock_14:0x800E9CA8).
- A column-0 goto label (clang-format) breaks a definition regex whose class spans newlines; exclude `:` (fixed in corpus.py CDEF_RE, 1.8/T10).
