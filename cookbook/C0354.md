# Documenting a file for docconv: DC4/DC5 traps

Where: adding DC1 banners and DC3-DC6 headers to existing C files (2.6 T7.c1-c4, ~90 functions).

- DC4 (basis line) is only checked once the file has a DC1 banner: adding a banner surfaces stale basis lines in
  headers that passed before. The basis line must quote the basis.tsv row text (`xref derived.tsv:15; xref:caller=<name>`).
- DC5 `callers:` takes bare names found in `config/symbols.<prog>.txt` only: `func_`/`D_` placeholders,
  `via D_80073ACC[...]`, `rock_00 x` are refused. Put placeholder callers on a free line
  (`// unnamed callers: func_...`) and dispatch on `// dispatch: D_80073ACC[action N] in update_player`.
  Write `callers: none known` when no named caller exists.
- Banner and header inserts move every `code:<path>:<line>` ref into that file (verdicts col 8, basis.tsv): see C0286.
- Banner range: lo = the file's first vram in `config/layout.tsv`, hi = the next row's first vram minus 4.
- docconv (2.6 T7) reads backslash-continued `#define` bodies as code: a `switch (...) {` / `if (...) {` line
  inside the macro is refused as `DC3 <word>`. A docconv fix, not a comment, clears it.
