# C0073 — Test sibling-game sharing under the target's compiler pin; vary only the compiler as the control
tags: prior-art,sibling-game,pin,control · date: 2026-10-01 · phase/task: 1.6/T8 · origin: mmx6 T8

To measure whether a sibling game's C shares bodies with the target binary, compile the sibling's C under the target's pin, not the sibling's own compiler. Control: change only the compiler; exact counts should track the target pin (here 1547 exact >= 8 words under X6's 2.95.2 vs 47 under mmx4's 2.7.2).
