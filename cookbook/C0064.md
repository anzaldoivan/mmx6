# C0064 — Verify c-unit conversions from a clean sync, because splat skips .s for functions only named D_<addr>
tags: splat,c-unit,nonmatchings,overlay · date: 2026-10-01 · phase/task: 1.6/T5 · origin: mmx6 T5

splat writes nonmatchings .s only for functions it finds. If the .c is already present, a function referenced only as `D_<addr>` gets no .s and its INCLUDE_ASM breaks. A tree where splat wrote the .c itself hides this. Verify every c-unit conversion from a clean sync of the tracked .c. Fix with name-only symbol rows, because a type:func row on a data-only reference turns data into a function.
