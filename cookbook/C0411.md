# C0411 — sched1 tie on a table address: assign the index locals in a comma expression inside the first index
tags: lever,sched1,tie,comma,index,table,order · date: 2026-11-08 · phase/task: 2.7/T9 · origin: mmx6 T9.c5 func_80052F64

1. **Residual (tell)**: Retail computes a table's address before two locals that index it. The draft computes the locals first. sched1 shows a tie between the two chains.
2. **Mechanism**: sched1 breaks the tie by insn order from the source. Assignments written before the expression come first.
3. **Lever**: Assign the locals inside the first index of the table read, as a comma expression. Example: `D_8007A154[TB][(n = arg0[2] & 0xF, i = n)][0]`. Then try the locals' declared types (`s32 n`) for any reg swap left.
4. **Byte proof**: 2.7 T9.c5, func_80052F64. The lever took 192 to 191 with an n/i reg swap. `s32 n` then gave MATCH 196/196, banked with no pins.
5. **Related**: C0404 (read the sched1 order), C0405 (sched1 hazard tie), C0182 (comma form).
