## DK-15 guards (as built)
- Hide = each `register … __asm__("…") …;` declaration wrapped `PERM_IGNORE(<decl>)` in base.c: upstream emits it verbatim (b64 pragma) so every candidate still compiles with the pin, but no randomizer pass sees or edits it. Cost: passes needing the pinned var's type raise `KeyError`/assert → counted as `permuter failures`, iteration continues.
- Restore = unwrap; asserted equal to the pre-hide text.
- K&R: definition of <func> with identifier-only params or declarations before `{` → `PERMUTE REFUSED K&R <func>`, rc 1.
- Zero iterations / no base score / restore mismatch → rc 1. Score 0 → `PERMUTE CANDIDATE … (not banked)`; no src/ write, no bank.py.
- Compile CFLAGS: candidate file stem is `cand`, so a per-TU `CFLAGS_<tu>` carve does not apply; T7.c2 should check its draft's TU has no carve row (or extend compile.sh then).
