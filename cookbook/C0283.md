# C0283 — Share one expensive gather between a checker's self-test and its run
tags: self-test,harness,cache,health,fleet · date: 2026-10-30 · phase/task: 2.3/T19 · origin: mmx6 T19.c1

Use: a checker's `--self-test` and its real run each pay for the same expensive gather (a full compile pass, a scan), so health pays twice.

Move:
- Let `--self-test` combine with the run flag in one process: self-test first, a failing control returns rc 1 and skips the run.
- Cache the real (unplanted) gather result the self-test computed (`P2_CACHE` in tools/mmx6/harness.py). The run reuses it. The planting step builds new lists, so the cache stays clean.
- Cache only gathers whose inputs the run cannot change between the two steps. mmx6 caches P2 (compiles) and never P3 (fleet).
- Point the make rung at the combined form (`harness.py --self-test --sampled`).

Evidence: mmx6 2.3/T19. th-harness ran P2 once (~20 min saved). Every pair's planted control still DISAGREE. Full fleet 25 min, was 31-37.
Trap: the combined rung still needs its prereqs (bound2, census, draw outputs). Run it via `make th-harness`, not straight after a fleet-quick that wiped build/.
