# C0093 — Prove an instrumented compile matches the build by diffing .text bytes, not RTL insn counts
tags: toolchain,dumps,control,gcc · date: 2026-10-02 · phase/task: 1.7/T2 · origin: mmx6 T2

To show `cc1 -da` (or any instrumented run) does not perturb codegen, assemble the run's own output and compare its .text with the built object's. RTL insn counts never equal object words (INCLUDE_ASM bodies, assembler nops, macro expansion).
