# ledger --build needs a fleet after the last sync

- `mx.sh sync` wipes /work except `.run` and `waves`, which includes build/ census/sig/draw/corpus outputs.
- `ledger.py --build` reads those outputs, so run it in the container after a `make fleet` that follows the last sync, then `mx.sh pull` the ledger.
- Symptom: fleet health rc 2 (ledger) after a rename batch. Fix: rebuild the ledger in the same volume state, then re-run the fleet.
