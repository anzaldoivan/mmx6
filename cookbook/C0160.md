# Callee-saved swap among loop invariants: add copies that combine later deletes

Symptom: a loop preheader holds the right invariants in swapped callee-saved registers (regalloc residual, a few words).
Cause: global alloc ranks equal-ref invariants by live length, which follows their preheader order. An invariant borderline in loop.c's pass-1 desirability test (`threshold * savings * life >= insn_count`; the `-dL` dump prints "not desirable") moves in pass 2 and lands after the others.
Lever: raise the loop's insn count with copies combine deletes later: route a load or a constant through an s32 local, then copy it into the narrow target, in each arm (`t = 0; t2 = t;` / `t = load; t2 = t;`). Diagnose with `cc1 -dL`.
Also: a pinned register variable used directly in a loop is never hoisted; copy it into a plain local in the loop guard so its product is hoisted.
Evidence: W12 SLUS 274A0 (c22 179/184 -> c64 184/184).
