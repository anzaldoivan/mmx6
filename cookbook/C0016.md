# C0016 — Ghidra headless refuses project paths with a dot-leading element. Reach the .run/ scratch via a symlink
tags: ghidra,headless,project,path · date: 2026-10-01 · phase/task: 1.2/T3 · origin: mmx6 T3

analyzeHeadless rejects a project location that contains a path element that starts with '.', for example `.run/ghidra/rebuild`. Create a symlink without a dot-leading element, for example `ghidra/rebuild -> ../.run/ghidra/rebuild`. Open the project through the symlink.
