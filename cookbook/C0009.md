# C0009 — fnmatch **/X misses root-level X; add a sibling root glob
tags: firewall,glob,fnmatch,audit · date: 2026-10-01 · phase/task: 1.0/T1 · origin: mmx6 T1

# fnmatch `**/X` does not match a root-level `X`

- Symptom: a firewall/audit glob `**/SCPH*.BIN` catches `a/SCPH1001.BIN` but not `SCPH1001.BIN` at the repo root.
- Cause: gitignore's `**/` matches zero directories; Python `fnmatch` treats `**/` as `*/`, which needs at least one `/`.
- Fix: add a sibling root rule beside every `**/X` glob (`glob: X` and `glob: **/X`). Probe both paths after adding.
- Source: mmx6 Phase 1.0 T1 (config/firewall.txt, tools/audit_public.py).
