# C0061 — Moving a type to a shared header: remove its copies from probe sources too
tags: types,header,probe,common.h · date: 2026-10-01 · phase/task: 1.6/T3 · origin: mmx6 T3

Probe sources include the same common header as product units, so a type moved into a shared header must be deleted from every probe file as well, or the probe compile breaks with conflicting types (here harness P2 caught it). Also make the header a prerequisite of C objects so a type edit rebuilds them.
