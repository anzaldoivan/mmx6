# A generated public doc must pass the commit gate's style lint

Problem: a generator (e.g. tools/mmx6/contract.sh) writes a tracked doc after a long run (~1 h). `commit_task.sh` runs the style gate (rules/STE1.md) on that doc. One finding refuses the commit: `GATE FAIL style: <doc>: 1 finding(s)`. The whole run must be repeated because the fix touches a build input (the generator), which changes C.

Move:
- Keep the generator's static prose and joiners style-clean before the first long run: no `;` in sentences, joiners `,`.
- Cheap pre-check: run the generator's doc-writing path on a stub (or commit a stub of the doc) through the gate before the long run.

Evidence: 1.9/T7.c1. Run 1 at c655f4e8 was green but the doc was refused. Fix 233d51b2, run 2 green, doc 6bebc6c6.
