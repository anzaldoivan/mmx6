# C0021 — Ghidra function starts without extents over-include data tails. Trim to the last jr ra + delay slot
tags: ghidra,export,function-extent,mips,compare · date: 2026-10-01 · phase/task: 1.2/T4 · origin: mmx6 T4

When you take a function body as [func start, next row) from an export that carries no extents, the span includes trailing data/padding. Before you compare code words, trim each body to the last `jr ra` plus its delay slot. An example is a comparison of image vs RAM dump. Print the denominator too.
