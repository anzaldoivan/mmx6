# C0017 — analyzeHeadless exits 0 when a script prints an error and returns; grep the script's error marker
tags: ghidra,headless,exit-code,wrapper · date: 2026-10-01 · phase/task: 1.2/T3 · origin: mmx6 T3

A GhidraScript that prints an error and returns does not change analyzeHeadless's exit code (0). Wrappers must have scripts print a fixed marker (e.g. `MMX6ANN ERROR`) and grep the log for it to set rc.
