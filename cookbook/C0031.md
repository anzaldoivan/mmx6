# splat psx, many asm subsegments: subalign 4

GNU as aligns `.text` to 16, and splat default `SUBALIGN(16)` / `ALIGN(.,16)` pads 4-aligned TU starts, breaking the hash. In the yaml options set `subalign: 4` and `ld_align_section_vram_end: false`.

Source: phase 1.3 T4 (splat 0.50.0, 246 TUs in SLUS_013.95).
