# C0117 — A splat blob whose fields retail loads by fresh high-half is several globals: one extern per field
tags: lever,splat,blob,extern,cse,hi-lo,global · date: 2026-10-03 · phase/task: 1.8/T13 · origin: mmx6 W4

1. **Residual (tell)**: Retail loads each field of a large splat data symbol with a fresh high-half address load per field. The draft declares the symbol as one array or struct extern. It folds all fields onto one base register (shorter, wrong registers).
2. **Mechanism**: This is observed. A splat blob (one `D_<addr>` spanning many original globals) is really several globals. For offsets of one symbol, cse shares one base, but not across distinct symbols.
3. **Lever**: Declare each used field as its own `extern T D_<addr>;` instead of offsets into the blob. The linker script's provided symbols define them.
4. **Byte proof**: In wave W4 (1.8/T13), rock_20:0x800EA1F0 is at 548/548 (banked at the W4 regate).
