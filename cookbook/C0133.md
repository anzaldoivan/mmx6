# C0133 — An inert control edit must reach the compiler: a code rider, never a comment
tags: control,inert,self-test,preprocessor,lever-credit · date: 2026-10-04 · phase/task: 1.8/T4 · origin: mmx6 harvest

- A control that proves an edit is inert (no byte change) must survive preprocessing. A comment proves nothing, because cpp strips it.
- Use a code rider that cannot change codegen, such as an unused local (1.8/T4).
