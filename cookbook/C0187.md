# Three inlined copies of one routine: a static inline helper called three times

Case: W19 SLUS_013.95:0x8001C1AC (banked, logs/T19.c11.md).
- Shape: the body repeats a retry loop three times (counter init, do-while, early return 0). Write one `static inline` helper (counter initialised at its declaration). Call it three times. The outer body returns early when the result is not 2. The last call goes through the result local before return.
- Gate risk: a twin banked later into the same TU repeats the helper → R2 "redefinition of static inline" (1.8 R2 cause list). Give the helper a function-unique name (`func_<addr>_try`).
