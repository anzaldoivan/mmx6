# Import a script that has no `__main__` guard

Problem: `tools/gen_objdiff.py` calls `main()` at module level. A plain import parses the caller's argv and writes files.

Move: parse the source with `ast`, drop the top-level `ast.Expr` nodes whose value is an `ast.Call`, then compile and exec the module into a `types.ModuleType`. Defs and constants stay. The script is unchanged, which matters when it is pinned or shared.

Example: tools/mmx6/badges.py `load_gen_objdiff()`, which uses `collect()`. Run with cwd at the repo root when the functions use relative paths.

Limit: calls hidden in `if` blocks or assignments still run. Read the module's top level first.
