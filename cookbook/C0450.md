# C0450 — A pin on a call-arg local: declare the shared global pointer inside each arm
tags: lever,pin,depin,register-pin,block-scope,pointer,regalloc,arms · date: 2026-11-12 · phase/task: 3.1/T17 · origin: mmx6 T17.c2 rock_34 func_800FB81C

## Problem
A register pin on a call-argument local (`register s32 py asm("$3")`) survives every order, type and temp change.
The real cause is upstream: one function-scope pointer to a global (`p = &g_Player`) shared by both if/else arms.

## Move
- Before any pin lever, find locals shared across arms (pointers to globals first). Declare the pointer, and the
  locals it feeds, inside each arm's block (C0109, C0122 applied to a pin).
- Moving only the pinned locals into the arms does nothing: the pointer's scope is what moves the allocation.
- Re-probe unpinned, then depin.py to confirm `pins 0 to 0`.

p+px+py per arm 114/114 pin-free, probe 5 of 25.
