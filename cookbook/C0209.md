# C0209 — Byte or field read for a test: block local numerically pinned to the first return register
tags: lever,register-pin,regalloc,load,byte,field,compare · date: 2026-10-13 · phase/task: 1.8.1/T28 · origin: mmx6 W28 rock_22 F259C

- Symptom: a byte or field read feeds a test or a compare. Retail loads it into the first return register. The draft loads it into another temp, so the branch and its delay slot differ.
- Lever: read the byte or field into a block-scope local. Pin that local numerically to the first return register. Then test the local, not the field.
- The pin fixes where the load lands. An order sweep alone does not move it.
- W28 used it in 11 packs. SLUS: 46148 and 515B4. rock_02: F6810. rock_03: EBCEC. rock_04: F3B28 and F55FC. rock_05: F2DEC. rock_08: F2CDC. rock_15: F1B98. rock_22: F259C. rock_43: FA52C.
- Related: C0141 pins constants only. C0182 pins a compare result through the comma form, when the value dies at the compare. C0179 pins an increment temp.
