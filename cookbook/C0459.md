# C0459 — Route an INBOX bullet with the word later: no phase ids, Gen N or arrows in it
tags: inbox,routing,later,guard,heredoc · date: 2026-11-13 · phase/task: 3.1/T24 · origin: T24 mmx5 inbox append

Symptom: an INBOX bullet meant for the next open phase is routed `now` or to a named phase. The loop routes on the first match. The order is `-> <id>`, `Gen N`, a later plan phase id such as `3.11`, then the word `later`. The current or an earlier phase id routes now.

Move: start the bullet with `later:` and keep every phase-like number out of it: no `3.1`, no `Gen 3`, no `->`. Name sections by word ("handoff section 3"), dates with dashes, commits by hash. Point at a doc for the detail.

Also: a Bash command whose text names the live plan file is refused by the guard (rule M17), heredocs included. Write such text with the Write tool, then `cat` the parts together.

Check: grep the appended bullets for `[0-9]\.[0-9]`, `Gen ` and `->`: no hit.
