# C0060 — Near-duplicate band: lossless prefilter by length and opcode-histogram bounds
tags: twins,near-dup,edit-distance,census · date: 2026-10-01 · phase/task: 1.6/T2 · origin: mmx6 T2

For a near-twin band (normalised edit distance over relocation-masked words <= RATIO), the length difference and half the opcode-histogram L1 are both lower bounds of edit distance, so they prefilter without loss. Functions under 1/RATIO+1 words can only be exact twins. Check the prefiltered set against a brute-force scan once.
