# XA attribute in the ISO9660 directory record is big-endian

The CD-XA system-use field of an ISO9660 directory record holds a 16-bit attribute word stored big-endian
(unlike the both-endian ISO fields around it). Bits: `0x1000` = Form 2 (mode 2 form 2: XA audio, STR video),
`0x2000` = interleaved.

Cross-check: the file's first sector subheader, submode byte bit 5 (`0x20`) = Form 2. Both must agree;
treat disagreement as an error.
