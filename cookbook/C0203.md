# C0203 — Assign the working pointer from the parameter on each path, not one entry copy
tags: lever,parameter,callee-saved,copy,regalloc · date: 2026-10-12 · phase/task: 1.8.1/T25 · origin: mmx6 W25 rock_09 F49C8

# Per-path parameter copy where retail reloads an argument from the callee-saved copy

Symptom: retail moves the parameter into a callee-saved register and reloads the first call's argument from that copy. A single entry copy (`p = arg0;` at the top) lets gcc reuse the incoming argument register instead.

Lever: assign the working pointer from the parameter separately on each path. Assign it once on the early-exit arm (before its goto) and once on the fall-through path. The copy is then not one shared entry instruction.

Seen: W25 rock_09 F49C8 (c52, 42/42).
