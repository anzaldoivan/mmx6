# C0051 — Narrowing control from the real population (hide one input dir)
tags: self-test,control,scanner · date: 2026-10-01 · phase/task: 1.5/T3 · origin: T3 optscan

A scanner's narrowing control can reuse its real population: symlink every real input dir but one into a scratch root and require the coverage check to refuse, naming the hidden one. Zero setup data; the real run doubles as the false-positive control.
