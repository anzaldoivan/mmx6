# C0294 — Rename never moves files, so its token rewrite must skip #include lines (func_X.c matches)
tags: rename,include,layout,role,token · date: 2026-10-31 · phase/task: 2.4/T6 · origin: mmx6 T6.c1

Problem: rename.py rewrites the old function name word-bounded across sources. `func_X` also matches inside
`#include "…/func_X.c"`. While renames moved the body file, the move and the include rewrite went together.
Now renames never move files (role files, T6). The rewritten include then points at a file that does not exist.

Move: skip `#include` lines in the token rewrite (tools/mmx6/rename.py). File names are paths, not symbols. A path
change is layout.py's job, never rename's.

Check: the rename self-test case "include paths unchanged". Also the two-function role file case: no file is created or moved.
