# Early return on the zero case, then a flat body: per-arm returns and no frame

When: retail has several separate return sequences and no stack frame. The draft's nested
`if (v != 0) { … }` around the main block gives one shared epilogue, and gcc builds a frame.

Lever: `if (v == 0) return 0;` first, then the body unnested. For a two-arm join, find the arm that
retail finishes on its own. Let that arm store its own constant and return early. Keep the join only
for the arm that jumps to it.

Evidence: W24 SLUS func_8003EB0C (T24): nested if 34/91, early return + flat body 91/91.
W24 SLUS func_8001FD10 (T24 c60, retry of c26): shared-join spelling plateaued at 86/89. The else arm with
its own constant store and early return gave 89/89. Related: C0181 (one early return per value in byte chains).
