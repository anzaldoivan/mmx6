# C0275 — Ghidra round-trip src diff: importer must set the row's source when analysis already holds the name
tags: ghidra,roundtrip,import,source,psx_ldr · date: 2026-10-26 · phase/task: 2.3/T4 · origin: mmx6 T4

When a round-trip (fresh import + annotation import + re-export) diffs only on a label's `src` (`USER_DEFINED` wanted, `ANALYSIS` got):
- The fresh import's analysis (psx_ldr signature match) already gave the address the same name.
- The importer's label step found the name, counted it `unchanged` and never set the source.
- It shows up once the live DB's names are mirrored to library names that analysis also finds (T4: `SsStart` at 0x80058DF4).
- Fix it in the importer: when the name matches but `sym.getSource()` differs from the row, call `sym.setSource(src)`. Do not edit the export.
- Prove it on one program first (`roundtrip.sh SLUS_013.95`: `labels=3` changed), then all 57.
- mmx6: tools/mmx6/ghidra/scripts/ImportAnnotations.java label() (2.3/T4).
