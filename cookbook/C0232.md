# Makefile has no header deps: touch the TU when a shared include changes
- Editing a shared .c file that a TU #includes does not rebuild that TU's object.
- Touch the TU (or force its rebuild) after changing a shared include.
- Judge the result on a clean build, since an incremental build can pass where the clean rebuild is red.
