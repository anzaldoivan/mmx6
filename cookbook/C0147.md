# A shared block-scope u8* scratchpad pointer fixes a callee-saved register swap

Symptom: a long per-object function matches in shape, but two callee-saved registers are swapped across
the whole body. The draft computes the scratchpad (or object byte) address separately in each block.

Lever: declare one block-scope `u8 *p` that holds the shared scratchpad base. Route the byte accesses of
every block through it (as `p[off]`), in the order retail stores them. The single long-lived pointer takes
the callee-saved register that retail allocated first, and the swap disappears.

Case: W8 rock_21:0x800E9864 (T8.c63, retry, 270/270), with per-object store order (C0135).
