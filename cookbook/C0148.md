# Read two globals into locals before either adjacent store

Symptom: the code copies two globals into adjacent fields at a join (shared high part of the address across
if/else). Retail loads both before the first store. The draft interleaves load-store-load-store, and the
second load lands in the wrong register.

Lever: write `a = G1; b = G2; obj->f1 = a; obj->f2 = b;`. The store-before-load spelling forces an alias order
(the store may clobber G2). Only the both-locals form gives the second load its own register.
For a large straight-line block of field stores, a random-move hill-climb over statement order scored by
the plateau residual found +6 beyond hand sweeps.

Case: W8 rock_03:0x800F3BE4 (T8.c37, 128/128). The twin rock_08:0x800EFF9C (W7 fail 137/153) should take it.
