# Disassemble a PS-X EXE with objdump as raw binary

```
mipsel-linux-gnu-objdump -D -b binary -m mips:3000 -EL \
  --adjust-vma=<load - 0x800> --no-show-raw-insn SLUS_xxx.xx > .run/<task>/exe.lst
```
- The PS-X EXE has a 0x800-byte header; file offset = vaddr - load + 0x800, so `--adjust-vma` = load - 0x800
  (load 0x80010000 → 0x8000F800) makes the listing addresses equal runtime vaddrs.
- The full listing is megabytes (~3 MB for 0x7F000 text): keep it under `.run/`, grep it; never print it.

Origin: mmx6 phase 1.1 T2 (locating the ROCK_X6.BIN loader).
