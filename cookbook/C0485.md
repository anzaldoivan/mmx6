# C0485 — A frozen artifact checked against a live table breaks when rows leave the table: freeze those rows, count them
tags: self-test,frozen,priorart,arm,ledger,banked · date: 2026-11-16 · phase/task: 3.3/T2 · origin: T2.c1 cards (o)

Symptom: a self-test fails after a routine rebuild of a live table, with no code change. At 3.3 T2 the table was
campaign/priorart.tsv. Check (o) of cards.py rebuilt the frozen 3.1 arm file (config/methods-arm.tsv) from it. All 9
sample rows of the arm had been banked, so they had left the ledger and the table.

Move: such a check takes the frozen value for each row that left the live input. It prints how many rows it froze
(`CARDS CONTROL (o) <k> rows frozen (left the ledger)`). A row still in the input must still equal the live value.
Reading the input at the blob the frozen file pins (C0427) needs git, and the container's /work has none.

Check: rebuild the live table and run the self-test. The frozen count equals the rows absent from the table.
Fix commit cdb3e08b (tools/mmx6/cards.py check (o)).
