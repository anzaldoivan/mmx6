# C0062 — A masked standalone match can name the wrong symbol; only the whole-binary hash catches it
tags: probe,masking,relocation,bank · date: 2026-10-01 · phase/task: 1.6/T4 · origin: mmx6 T4

A probe that masks relocations matches a body that references the wrong table or callee. The standalone match is not a bank (G10): keep the clean-rebuild whole-binary hash (or a per-member unmasked linked compare) as the last rung, and plant a wrong-symbol control that must match standalone and stop there.
