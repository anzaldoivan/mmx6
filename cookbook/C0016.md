# C0016 — Ghidra headless refuses project paths with a dot-leading element; reach .run/ scratch via a symlink
tags: ghidra,headless,project,path · date: 2026-10-01 · phase/task: 1.2/T3 · origin: mmx6 T3

analyzeHeadless rejects a project location containing a path element that starts with '.', e.g. `.run/ghidra/rebuild`. Create a symlink without a dot-leading element (e.g. `ghidra/rebuild -> ../.run/ghidra/rebuild`) and open the project through it.
