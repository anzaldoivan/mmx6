# C0106 — Shared function-scope local across a repeated block raises its allocation priority
tags: idiom,sym-sreg-swapped,regalloc,global-alloc,macro,priority · date: 2026-10-03 · phase/task: 1.8/T10 · origin: mmx6 W1

1. **Residual (tell)**: two callee-saved registers swapped between `self` (or another long-lived pseudo) and a local reused by a repeated block; schedule and length already match.
2. **Mechanism**: gcc 2.95 global.c `allocno_compare` orders pseudos by `floor_log2(refs) * refs / live_length`; one local shared by two copies of a block collects the refs of both and outranks `self`, so it takes the first callee-saved register. Two block-scoped locals each stay below `self`.
3. **Lever**: write the repeated block as a brace macro expanded twice (or two copies) that both assign one local declared at function scope, instead of a local declared inside each block.
4. **Byte proof**: wave W1 (1.8/T10), rock_06:0x800E9A30 plateau regalloc 42 words → 203/203 (banked); a brace macro with block-local `y` alone stayed at 42.
