# G103 — A probe compiles through the product build's rule, never a copied flag set
id: G103 · group: G · status: active · tags: decomp,probe,pin,build · origin: mmx6 1.4/T3 · added: 2026-10-01

A compiler probe compiles through the same rule the product build uses (one pipeline: cpp, cc1, assembler shim, as, flags
selected by the triple name), never through a copied or hand-assembled flag set. A pin is then the product build's pin by
construction, and a later flag change reaches probes and C units together.
provenance: mmx6 1.4 T3 (probe.py drives `make` per triple), T7 (pin = Makefile default TRIPLE)
