# C0036 — Ubuntu make recipes run under dash (no pipefail); set SHELL bash + .SHELLFLAGS per target
tags: make,pipefail,dash,ubuntu · date: 2026-10-01 · phase/task: 1.4/T2 · origin: mmx6 T2

GNU make on ubuntu uses /bin/sh = dash, which rejects `set -o pipefail`. For a pipe rule set target-specific `SHELL := /bin/bash` and `.SHELLFLAGS := -o pipefail -c`; prove it with a negative control (a dead stage gives make rc 2).

Source: phase 1.4 T2 (build/%.c.o rule).
