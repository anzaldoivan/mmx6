# C0015 — GhidrAssistMCP headless: stop via completion_file so the project saves; killing the JVM skips the save
tags: ghidra,mcp,ghidrassistmcp,headless,save · date: 2026-10-01 · phase/task: 1.2/T2 · origin: mmx6 T2

GhidrAssistMCP's headless wait mode ends cleanly, saving the program and releasing the project lock, when the file named by its `completion_file=` option appears. Killing the JVM (pkill/SIGTERM) skips the save. Import/export need the server stopped (project lock).
