# One destination pointer local reused across both branches keeps one global pseudo

Symptom: two copy branches each with their own destination pointer; the pointer lands in the wrong callee-saved register in one branch.
Cause: two pointer locals make two pseudos that global-alloc colours separately; retail uses one register for the destination in both branches.
Lever: declare one `dst` local before the branches, advance it with `*dst++` in the first copy loop, and reuse the same local (reassigned) for the second branch; one pseudo then spans both branches and takes the target register.
Evidence: W15 rock_09 ED18C (palette fade; closing lever after load-order fixes).
Related: C0142 (one reused s32 local carrying two values).
