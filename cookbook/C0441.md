# C0441 — mmx5-dev dedup members are stubs: apply the stub's defines to its src/shared body
tags: x5,mmx5-dev,dedup,seed,prior-art,stub · date: 2026-11-10 · phase/task: 3.1/T10 · origin: mmx6 T10.c1

- Symptom: an X5 function's file under mmx5-dev `src/slus/` or `src/rockx5/` is C (no INCLUDE_ASM) yet holds no body, about 6 lines.
- Cause: a dedup member is a stub, `#define DEDUP_NAME <name>` plus other defines, then `#include "../shared/<x>.c"`.
- Move: read the stub, then `git -C ../mmx5-dev show HEAD:src/shared/<x>.c`, and apply the stub's #defines to that body before using it as a seed (cards.py --x5-fetch does this).
- Renaming X5 C to X6 names without mmx5 headers: use the x5-leads relocation map first, then the twin join with one candidate.
- Otherwise keep the symbol with a `/* X5 */` marker and count it.
