# C0461 — A self-test probe must use its own --probes dir, or it spends the real probe cap
tags: probe-cap,self-test,cards,x4port,volume,fleet · date: 2026-11-14 · phase/task: 3.2/T2 · origin: 3.2 T2.c6

- Symptom: after 6 fleets on one volume, th-selftests-cheap fails with `X4PORT CONTROL FAIL positive` and `PACK ... refused probe-cap a1 6/6`. Clean HEAD fails the same way.
- Mechanism: a self-test that calls `cards.py --probe-pack` bumps the shared per-pack counter in waves/.probes. That counter persists in the volume across fleets.
- Move: a self-test probes with `cards.py --probes <its own scratch dir>` and removes that dir afterwards. The real cap for wave packs is unchanged.
- Never delete a waves/.probes counter by hand: auto mode refuses it as a security weakening.
- Evidence: 3.2 T2.c6 (ce7d64f8), 7 x4port self-tests in a row on mmx6-t2 with the stale 6/6 counter present, all CONTROL OK. FLEET 57 of 57 rc 0.
