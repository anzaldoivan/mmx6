# Per-stage object dispatch tables: find them through the scratchpad setter, prove them with table[id]==fn

Problem: object class loops (e.g. SLUS func_8002000C, func_80020258) call `(*0x1F8000xx)[obj[1]](obj)`. The table pointer lives in scratchpad and is set per stage, so no static xref leads to the table.

Move:
- Find the `sw` that writes the scratchpad slot (here the stage loader 0x80013E8C..0x80013F50: `*0x1F800080 = D_8006DC6C[stage*2+sub]`, `*0x1F800084 = D_8006DD24[i]`, member u16 `D_8006DB78[i]`).
- Static: read each stage's table from its overlay member bytes (file offset = vram - overlay base). Length: the tables of one stage are contiguous. A table ends at the next table's start or at the first word that is not a KSEG0 code pointer. A bare "first non-code word" scan overruns because neighbouring overlays also hold code.
- Runtime (PCSX-Redux, C0019): Exec breakpoints on the setter (dump the table words once per load) and on the dispatch `jalr` (log id, target, frame). Assert `table[id] == fn` for every hit. Static equals runtime → the static join holds for stages the input cannot reach.
- Spawn lists: records {flags,id,subtype,type,x,y}, `type & 0xF` picks a class allocator from a small fn-pointer array. The record's `id` becomes obj[1].

Tools: tools/mmx6/redux/objects.lua, tools/mmx6/objmap.py → docs/leads/objects.tsv.
