# C0071 — Family-only siblings differ in a non-relocated field; relocation remap gates few
tags: family,remap,dedup,relocation · date: 2026-10-01 · phase/task: 1.6/T7 · origin: mmx6 T7

A sibling differing only in relocation targets already shares the dup key (relocations masked), so a sibling in the family but outside the dup class always differs in a non-relocated field (here one load offset immediate). Expect positional relocation remap to gate few; such siblings need a parameterised body. Read a banked function's relocations from its C object (C0047).
