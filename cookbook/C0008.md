# dumpsxiso -x puts non-ISO files in the output dir

dumpsxiso writes `license_data.dat` (the system area) inside its `-x` directory. On discs that have a CD-DA track, it
also writes Track 2 audio there as `*.WAV` for `da` entries. Mega Man X6 is a single data track, so expect only
`license_data.dat`. Move these files out before you diff against an ISO-tree extractor. Otherwise the diff reports them
as Only-in. This entry comes from dino-crisis-2-decomp (Phase 1.1 T2, 2026-09-30).
