# C0454 — diff.sh in the container: set MX6_PROG for an overlay and pass --no-pager
tags: diff,asm-differ,mx.sh,container,pager,overlay · date: 2026-11-13 · phase/task: 3.1/T18 · origin: mmx6 T18.c1 W305

Symptom: `mx.sh run bash tools/mmx6/diff.sh <func>` hangs or prints nothing useful for an overlay function. The image has no `less`, and asm-differ pages by default.

Fix: `mx.sh run env MX6_PROG=<prog> bash tools/mmx6/diff.sh <func> --no-pager` after `make expected`. Pass: `DIFF <func> 0 differing lines`, rc 0.

Evidence: 3.1 T18.c1, 20 of 20 holdout banks diffed this way (.run/3.1/logs/t18c1-diff3.log). The first two tries (diff, diff2) lacked one of the two.

Related: scratch TU compiles for splice diagnostics must write outside /work/build: a scratch `rm -f` of TU objects there stopped 4 gate rows (T18.c1 gate3).
