# C0330 — New include in concatenated units goes before the first use, not after the first x4.h
tags: include,header,preamble,unit,role-file,hoist · date: 2026-11-02 · phase/task: 2.5/T10 · origin: mmx6 T10.c1

## Problem
Adding an `#include` to role/unit files: "after the first `#include "mmx6/x4.h"`" put it below uses -> `undeclared`.
## Mechanism
Units concatenate several member preambles, so a file can hold several include blocks mid-file.
The first x4.h include may sit after a body that already uses the symbol.
## Fix
Place the new include after the last `#include` that precedes the file's first use (or first removed decl line).
