# C0143 — Clamp by storing the compare result in the clamp variable and branching on it
tags: lever,clamp,compare,jump,regalloc · date: 2026-10-05 · phase/task: 1.8.1/T6 · origin: mmx6 W6

Symptom: for a min/max clamp (`v = t < 6 ? t : 5`), retail computes the compare into the clamp variable's register. The draft hoists the constant arm above the compare.

Lever: store the compare result in the clamp variable and branch on it: `var = t < 6; if (var) var = 5; else var = t;` (or the matching sense). Branching on the variable stops jump optimization hoisting the constant arm, so the clamp shares the compare's register.

Evidence: phase 1.8.1 T6 rock_03:0x800F5564 (logs/T6.c<k>.md).

Check: the slt result and the stored clamp share one register in retail.
