# Switch on an unsigned index for equality-only case tests

Symptom: a small switch (cases 0..2 or 0..3, no jump table) compiles to a balanced compare tree with `slti` splits. The target tests each case with plain equality (`beq`/`beqz` chain).
Lever: write `switch ((u32)x)` (or use a `u32` local that holds the selector). With an unsigned index, 0 is the type minimum, so gcc 2.95 bounds the tree differently and emits equality leaves.
Evidence: W12 SLUS 2E1A0 (c24, 3 cases on s32: 131 -> 183 of 183), rock_18 EAAC0 (c27, signed-byte result, cases 0..3).
Related: C0113 (if/else-if chain instead of a switch), C0137 (s8 switch).
