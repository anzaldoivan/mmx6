# C0045 — A trailing # comment on a make VAR ?= value line keeps the space before # in the value
tags: make,variables,comments · date: 2026-10-01 · phase/task: 1.4/T6.1 · origin: mmx6 T6.1

`TRIPLE ?= foo # note` sets TRIPLE to `foo ` (trailing space). An exact match (awk row lookup, filter) then fails. Put the comment on its own line.

Source: phase 1.4 T6.1 (Makefile default TRIPLE).
