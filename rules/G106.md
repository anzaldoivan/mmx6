# G106 — A shared body is one src/shared file included per member; members differ only by name defines
id: G106 · group: G · status: active · tags: decomp,dedup,bank · origin: mmx6 1.6/T4,T5 · added: 2026-10-01

A body shared by a dup class is one file under `src/shared/<system>/<name>.c`, banked by replacing each member's
INCLUDE_ASM line with `#include "../shared/<system>/<name>.c"`; never a macro body. A non-exemplar member differs only
by `#define <exemplar fn> <member>` and `#define <exemplar table> D_<absolute addr>` (address from the member's retail
hi/lo pair) around the include, `#undef` after. Every member has a row in `config/dedup_registry.txt`;
`propagate.py --check` recomputes each member's key from the build and refuses drift, a missing member, or a row
outside the class. Each member is gated by the reconcile ladder plus a per-member unmasked linked compare.
provenance: mmx6 1.6 T4, T5 (416 of 416 members gated, REGISTRY OK 416 rows), T7 (family rows); G7, G10
